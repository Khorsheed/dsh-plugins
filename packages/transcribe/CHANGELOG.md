# 变更记录

## 0.1.0（2026-10-26）

首个公开发布：本机转写——在这台电脑上把长录音转成带时间的文字，还能分出谁在说话。你不用直接操作它：剪辑里的分人与转写、灵感空间给没字幕的视频和播客出文稿，用的都是它（随「学习套件」或「剪辑套件」安装）。

- **长录音转成带时间的文字**：每句都标起止时间；不分说话人时在真实停顿处切块（Silero VAD），一句话不会被拆进两段。
- **中英文都行**：中文用 Paraformer，英文与自动判断语种用 SenseVoice；英文单词之间的空格会还原。
- **分出谁在说话**：先抽样比对音色判断是不是只有一个人（约 1 秒），一个人就不再分；多人时用声纹聚类分人（两小时访谈约 3–4 分钟），也可以只分说话人、不重新识别文字。
- **边转边出、可以续跑**：转完一段先给一段；可从某一秒接着转，返回的仍是绝对时间。
- **所有插件共用一条队列**：同一时间只转一个任务，可以撤下或停止；模型断点续传下载，剪辑插件里已下载的模型首次使用时自动挪过来。
- **不离开你的电脑**：识别在本机完成，录音不上传。

技术面：作为宿主服务 `transcribe` 供其它插件探测调用（`onSegments`、`fromSec`、`speakers()`）；设计见 Agent Note `2026-10-20-transcribe-engine`、`2026-10-20-transcribe-vad-chunks`。
