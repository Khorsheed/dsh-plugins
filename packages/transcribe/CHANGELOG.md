# 变更记录

## 0.1.0（未发布）

新增 `fromSec`：从单个文件的某一秒开始转写（续跑用），返回的时间仍是绝对时间。

新增 `speakers()`：只分说话人、不识别文字（转写稿已有时用）；先抽 24 段音色做一人判断（约 1 秒），一人直接返回；多人用 CAM++ 声纹聚类分人（两小时访谈约 3–4 分钟，pyannote 要 20 分钟以上；剪辑插件的分人转写仍用 pyannote）。

不分说话人的任务改为在真实停顿处切块（Silero VAD，新模型 `vad` 1.8 MB）：选最长的停顿切、短停顿接缝去掉凭空的句号并还原大小写、块首英文单词补空格；SenseVoice 不再套用 Paraformer 的英文空格规则。见 `2026-10-20-transcribe-vad-chunks`。

首个版本：从剪辑插件抽出的本机语音管线（子进程识别、分说话人与声纹、模型断点续传下载），作为宿主服务 `transcribe` 供其它插件调用。新增 SenseVoice（英文与自动语种）、可选分说话人、边转边出（`onSegments`）、所有使用方共用的单任务队列与撤下/停止；Paraformer 转写里的英文单词恢复空格。已下载在剪辑插件目录里的模型首次使用时挪过来。设计见 Agent Note `2026-10-20-transcribe-engine`。
