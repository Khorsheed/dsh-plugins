# 变更记录

## 0.1.1（2026-10-27）

- 学习模式里会话第一次写入图书馆（建项目、加教材、排路线）时，右侧栏自动打开图书馆，并直接进入这个会话绑定的项目页，不再停在首页；「‹」照样回到首页。之后手动关掉再打开页签，仍从首页开始。
- `library_textbook` 工具说明：核对教材版本和目录时，搜索写书名 + 作者或 ISBN，并用 `site:` 限定到书目或出版社页面（豆瓣读书、WorldCat、出版社域名），每个要区分的版本单独搜一次；搜索词里不写 `"`（裸引号会弄坏工具调用的 JSON）。配合宿主 0.2.1-rc.2 起的 DeepSeek Search API（支持 `site:` 等操作符）；旧的 Messages 搜索不保证认这些操作符，但照样按关键词匹配。

## 0.1.0（2026-10-26）

首个公开发布：图书馆——让 agent 当你的读书教练，帮你排进度、记笔记、出题，还盯着你把错题订正对。随「学习套件」安装，只在学习模式的会话里出现。

- **说清读什么就能开始**：书名和版本说清楚就够，不用上传整本书；只说想学的领域也行，教练照你的底子挑知识点和教材。
- **路线你点头才算**：教练照目录起草学习路线，你点「采用」才生效。路线是一条竖排的课程轨道，每一站是一课（3–5 个考点），标着状态和考点进度；没有哪一站上锁，可以跟着走，也可以挑感兴趣的先学。
- **每站一份讲义**：从站点导引的「开始学这一站」打开讲义页，讲义就是这一课本身（参考资料放在最后），覆盖这一站的每个考点；进站时才写，旧版本保留。
- **拍一页就能记笔记**：读到哪页拍一下，划线和页边批注自动整理成卡片。
- **学完一站就测**：每一站都是一套带考点的小测，题目从你划过、问过、做错的内容里出；选择填空当场出分，问答题教练来批；过关后教练问你下一站学什么。
- **错题不翻篇**：答错的题进「待订正」，订正对了才算掌握这个考点；「今日」把待订正的题和该复习的卡片列好。
- **书和项目页一目了然**：封面、干净的书名、分段进度条，目录默认折叠；删除前用宿主的确认框按类列出会删掉什么。
- **教练的工具面精简**：工具描述和提示词大幅瘦身（工具约 23.9k → 10.7k 字符，提示约 2.8k → 1.2k），结果更短并附下一步；讲义放错位置时直接告诉它怎么改。
