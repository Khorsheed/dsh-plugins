# 变更记录

## 未发布

- **切走再回来，文件树还是原样**：切到别的侧栏页签或别的页面再回来，展开的文件夹、已载入的内容和滚动位置都会恢复（按会话 + 当前目录分别记住）；回来时会顺手重新列一遍展开的文件夹，期间新增或删除的文件照样显示。之前每次回来都全部收起、滚回顶部
- **图片加载失败会说出来**：预览里加载不了的图片显示成「⚠ 图片加载失败：说明」链接——远程图片点开原地址（能看出是不是网络问题），本地图片点了在面板里打开那个文件；之前是悄悄只显示说明文字
- **Markdown 预览显示图片、点链接跳转**：README 里的 `<img>`（含外层 `<p align="center">` / `<a>`）在预览里显示成图片；`docs/x.png` 这类本地图片按文档所在目录找到并显示；`[English](README.en.md)` 这类本地链接点了就在面板里打开那个文件。代码块里的示范 HTML 不受影响，源码与编辑不变
- **就地编辑**：详情区标题行新增「编辑」，源码面变成文本框、预览页签同步显示草稿，⌘S 保存；新 Remote `localFiles/writeFile` 只写已存在、完整载入、UTF-8 无损的文本文件，先写同目录临时文件再 rename（保留权限、跟随符号链接到目标）；文件在编辑期间被改过时答 `conflict`，界面给「仍然覆盖 / 放弃修改，重新载入」；未保存的草稿按会话+路径保留，切走再回来还在。手机等非本机页面只读
- **标题行调整**：「复制路径」紧挨着「编辑」，之后是「重新加载」「打开所在文件夹」；「在 IDE 中打开」收进 ⋯ 菜单（找到几个 IDE 就各占一行）

## 0.1.3（2026-10-22）

- **文件树按文件名搜索**：新 Remote `localFiles/search` 在宿主侧一次遍历，大小写不敏感、按根相对路径匹配——文件夹名命中即列出其中内容（搜 `web-eval` 能直接进到里面的文件）；命中项的祖先目录自动展开，结果行可自由折叠（名字被命中的文件夹默认折叠、内容按需展开）；不进入 `node_modules`/`.git`、不跟符号链接，上限 200 条命中 / 5 万节点 / 16 层，截断与无命中各有明示；输入 200ms 防抖，Esc 清空查询
- **窄面板/手机自适应布局**：接入共享 AdaptiveSplit——≤560px 时列表与详情单面切换，选中文件进详情、返回不清选择也不丢已读内容；紧凑头部合并为一条可点按的面包屑（home 折叠为 `~`、当前文件夹加粗、过长横向滚动并停在末尾），取代原先的文件夹名 + 父路径 + 上箭头三件套；打开文件时唯一标题行让给预览的返回；文件名改为主色调，触屏行高 44px
- **非本机浏览器隐藏拉起宿主程序的手势**：「选择工作区 / 打开此文件夹 / 在 IDE 打开」只在 loopback 页面显示——手机经隧道访问时点这些手势什么都没发生的旧行为消除；命名统一：对文件是「打开所在文件夹」，对文件夹是「打开此文件夹」
- 修正「显示隐藏文件」开关 tooltip 的语病（worktrees 同改）
- 适配宿主 0.2.1 线：退役 invariant 伴生（其中一条 node-runtime 自检探针随之下线）并声明 `engines.dsh`（`>=0.1.5-rc.1 <0.3.0-0`）；peer 区间加 `|| ^0.2.1-rc.1`（严格解析路径下 `^0.2.0-rc.1` 不覆盖 0.2.1）；verifiedHost 前移 0.2.1-rc.1

## 0.1.0（2026-09-26）

首个公开发布（npm 首发，原 `0.1.0-rc.1` 未发布线转正）。文件列表浏览器首发线（自 worktrees 拆出后的独立包）。

- README 中英双语按仓标准补齐：已知限制 / 实现原理 / 开发 / 变更记录章节；数据面 verb 名订正为现行的 `listDirectory` / `readFile`（旧稿残留更名前的 `listLocalDirectory` / `readLocalFile` / `readLocalImage` 三名）
- 详情面板标题行新增「重新加载」手势（共享内容面板的 `onReload`）：重走 `readFile` 读当前选中文件，磁盘上的改动不必重选即得；重读期间旧内容保持显示、按钮禁用并旋转图标，失败保留旧内容、错误走既有共享 error 槽；晚于选择变更到达的旧答案丢弃。

- 内容搜索不再劫持视图：命中经 CSS Custom Highlight API 画在渲染后的 markdown / JSON 树 / CSV 表 / 代码视图上（`::highlight()` 外包 `:global()`，否则 lightningcss 会像类名一样改写标识符导致静默不上色）；只有渲染态确实看不见的查询（如搜 `**`、命中落在折叠的 JSON 节点里）才回落到原始命中行视图。计数在绘制态按可见出现次数（绘制上限 2000 个 Range），HTML 沙箱预览与不支持该 API 的宿主行为不变。

- 唯一入口：右栏 page-type tab（kind 级 extension 压 builtin 接管官方 `files` 类型，guide 页单张「文件列表」卡片，官方「工作区文件」卡片卸载即恢复）；minHost `0.1.5-rc.1`
- 默认根目录 = 本会话工作区（与官方文件树同一数据源：会话行 `cwd` 响应式读取，晚到补入）；手动切换目录按会话记忆（localStorage `dsh-local-files-root:<sessionId>`），重开/重载恢复；工具行「退回原始工作区」一键回根（已在工作区时隐藏，自绘文件夹回退图标）
- 「打开目录 / 在 IDE 打开」走官方 open-in-app 路由（`GET /open-in-app/apps` 探测 + `POST /open-in-app/open`，仅目录；探测失败静默隐藏）
- 2026-09-10 退役：`conversation.view` 会话 tab（入口收敛到右栏；随之移除 ui-conversation 依赖与 composer-overlay 底部留白）
