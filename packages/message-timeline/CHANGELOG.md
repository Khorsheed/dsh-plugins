# 变更记录

## 0.2.5（未发布）

- **整会话一次列出，首条消息即刻可达**：列表改读宿主 `turnOutline` 投影（每轮一条：轮次号、`turn/start` 序号、50 字首条预览），与已加载窗口合并——不再靠逐页翻历史才能看到更早消息。未加载轮次的行点击后经会话 jump loader（`ISession.loadThrough`）回翻历史再落位；行物化即落位，翻页停滞或轮次不可达时落到其后最近可见行。
- **静止态对比度调整**：所有行统一压淡灰刻度（不再区分已加载/未加载），只有当前阅读位置为蓝色加长刻度加粗行文字（无选中时默认最新一条）；回翻中的行以刻度脉动提示。
- 装配未挂载 turn-outline 单元时退回原窗口分页行为（打开预取 + 面板滚顶翻页），`initialPages` 只作用于该兜底路径。
- 注入面变化：`jumpTo` 现在返回是否命中（供落位重试），新增 `loadThrough`。

## 0.2.4（2026-09-30）

无功能变更。加宽 `@deepseek-ai/dsh-*` peer 区间以覆盖宿主 0.2.0（0.2.0 的兼容闸会禁用 peer 区间不覆盖宿主版本的已装插件）。

## 0.2.3（2026-09-27）

无功能变更。随宿主 0.1.7-rc.2 基线发布波重发：全量构建+测试在 rc.2 基线通过（rc.1→rc.2 无触及本包的宿主变更）。

## 0.2.2（2026-09-26）

适配宿主 rc.1 线并实证 0.1.5/0.1.7 双线可用（0.1.5-rc.1 全量 boot 实证，2026-09-25）。

- 会话面迁移：宿主移除 `ISessions.open/current` 后的读面切换
- 插件清单展示元数据（`locale/*.json`）：rc.1 宿主插件页的卡面标题/描述中文化

## 0.2.1（2026-09-11）

- 无功能变更：开发基线随仓内 pin 对齐官方 `0.1.5-rc.1` / cordis `4.0.2`（消除 4.0.1/4.0.2 双实例图分裂）；peer 依赖范围与 minHost（`0.1.2-rc.1`）不变

## 0.2.0（2026-09-10）

适配宿主 0.1.2 线。

- **BREAKING**：minHost 前移至 `0.1.2-rc.1`；宿主 `0.1.0-rc.6` ~ `0.1.1-rc.2` 的用户请停留在 0.1.x 线（末版 `0.1.0`）
- 聊天快照改读 0.1.2 的 `useChat` 单座席（rc 线的 `useSession(...).chat` 读取臂退役）；座席缺席时面板静默隐藏，绝不报错
- 导入面迁移：client bundle 不再引用宿主已删除的 `dsh-client-runtime`

## 0.1.0（2026-08-22）

首个公开发布。

- 会话左缘一条悬浮时间轴，每行一条用户消息（steering 消息可配置关闭）
- 环境化静止态：日常只显示压淡的刻度细线，悬停或聚焦才展开文字预览
- 阅读位置跟踪：当前位置的刻度保持高亮，停在超长回复中时锚定在所回答的用户消息上
- 点击行直接把会话滚动到对应消息，列表跟随阅读位置
- 长历史友好：更早历史在面板滚动到顶部时按需翻页加载
