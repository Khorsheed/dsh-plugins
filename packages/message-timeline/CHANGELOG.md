# 变更记录

## 0.2.5（2026-10-22）

- **整会话一次列出，首条消息即刻可达**：列表改读宿主 `turnOutline` 投影（每轮一条：轮次号、`turn/start` 序号、50 字首条预览），与已加载窗口合并——不再靠逐页翻历史才能看到更早消息。未加载轮次的行点击后经会话 jump loader（`ISession.loadThrough`）回翻历史再落位；行物化即落位，翻页停滞或轮次不可达时落到其后最近可见行。
- **静止态对比度调整**：所有行统一压淡灰刻度（不再区分已加载/未加载），只有当前阅读位置为蓝色加长刻度加粗行文字（无选中时默认最新一条）；回翻中的行以刻度脉动提示。
- **无文本预览的消息保留展示**（标记「无文本预览」），不再过滤；**修复自动轮次点击无反应**：重启恢复、定时任务等轮次在聊天视图渲染为 turn-trigger 卡片而非 user 行，原落位只找 user 行导致永远落不到。落位改为官方同款 `user ?? loaded[0]`：优先该轮首个 user 行，没有则落该轮第一个可见节点（触发卡片、图片气泡均可达）。
- **自动轮次成为一等行，选中不再跑偏**：turn-trigger 纳入时间轴行 kind——已加载时直接显示触发正文，未加载时标记「第 N 轮」；阅读位置锚点也认触发卡片，跳转后选中保持在该轮，不再跳到下一条用户消息。图片/附件消息分别标记「图片消息」「附件消息」。
- **窄布局不再隐藏时间轴**：右侧栏打开或窗口窄导致左沟槽不足最小宽度时，不再整条隐藏，而是退为左缘刻度条（24px，落在消息流留白内），悬停/聚焦时展开带底色的浮层；宽布局仍按沟槽封顶宽度。修复 Room 会话右侧栏展开时时间轴消失的问题。
- **修复 Room 会话时间轴高度为零**：Room 输入框以 overlay 接管输入区时，官方输入栏仍以 `display:none` 留在 DOM 里，测高误取它的零尺寸卡片，面板被压成几像素（只露一截蓝色刻度、打开时一闪而过）。现在跳过未布局的卡片，退到输入区顶边。
- **悬停浮层高度随消息条数**：窄布局悬停展开时，底色不再铺满从标签条到输入框的整段高度；面板高度随行数、在原位置垂直居中，条数多时才铺满并滚动。
- 装配未挂载 turn-outline 单元时退回原窗口分页行为（打开预取 + 面板滚顶翻页），`initialPages` 只作用于该兜底路径。
- 注入面变化：`jumpTo` 现在返回是否命中（供落位重试），新增 `loadThrough`。
- **适配宿主 0.2.1 线**：`@deepseek-ai/dsh-*` peer 区间追加 `^0.2.1-rc.1`（`^0.2.0-rc.1` 在 npm/pnpm 严格解析下不覆盖 0.2.1 预发布三元组）；宿主 0.2.1 移除 invariants 体系，随包 invariant 伴生退役、兼容判定改由 package.json `engines.dsh` 声明；`dsh.compat.verifiedHost` 前移至 `0.2.1-rc.1`（全量构建+测试在该树通过，无其它表面变化）。

- 长历史友好：更早历史在面板滚动到顶部时按需翻页加载
