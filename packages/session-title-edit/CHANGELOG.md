# 变更记录

## 0.2.2（2026-09-26）

适配宿主 rc.1 线并实证 0.1.5/0.1.7 双线可用（0.1.5-rc.1 全量 boot 实证，2026-09-25）。

- 紧凑编辑器行的取消/保存按钮改 `size="sm"`（28px，与该行输入框同高；宿主 Button 两条线 API 相同）
- rc.1 的 locale 注入面从 `settingsScope` 迁到 `configForms` 探测
- 图标自持化：rc.1 图标图样由 `sync-icon-artwork` 生成器摊平进包内 `src/client/icons.tsx`（双线渲染同一份图样）
- 插件清单展示元数据（`locale/*.json`）：rc.1 宿主插件页的卡面标题/描述中文化

## 0.2.1（2026-09-11）

- 无功能变更：开发基线随仓内 pin 对齐官方 `0.1.5-rc.1` / cordis `4.0.2`（消除 4.0.1/4.0.2 双实例图分裂）；peer 依赖范围与 minHost（`0.1.2-rc.1`）不变

## 0.2.0（2026-09-10）

适配宿主 0.1.2 线。

- **BREAKING**：minHost 前移至 `0.1.2-rc.1`；宿主 `0.1.0-rc.6` ~ `0.1.1-rc.2` 的用户请停留在 0.1.x 线（末版 `0.1.0`）
- 重命名失败错误码双兼容：同时识别 0.1.2 命名空间化的 `session/title-invalid` 与旧的 `title-invalid`
- 导入面迁移：client bundle 不再引用宿主已删除的 `dsh-client-runtime`

## 0.1.0（2026-08-22）

首个公开发布。

- 聊天头部标题旁的铅笔入口，点击后标题本身变成内联编辑器，预填当前标题并全选
- Enter 提交、Escape 取消、空草稿禁用保存，宿主拒绝时内联提示
- 输入框宽度随草稿自适应，上限为官方 220px
- 超过宿主 80 UTF-8 字节标题预算的草稿被本地化警告拦下，绝不静默截断
- 走官方 `session.rename` RPC，标题永不进入模型上下文
