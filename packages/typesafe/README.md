# @khorsheed/dsh-typesafe

[English](README.en.md) | 中文

协作间里那些「要不要合并」「现在告诉你还是等一等」的小判断，交给它来做，又快又能查。

在协作间里同时派了好几件事，你随手补一句话，它是在补充刚才那件事，还是一件新事？几个成员陆续交回结果，是来一个就告诉你一次，还是等齐了一起说？以前这只能按死规则来。装上快速决策，协作间会在没有明确规则时问它一句，大约一秒拿回答案：把你的话合并到对应的任务里，或者把结果攒一攒再统一汇报。每次判断都有记录，打开「上下文透镜」的「房间」页签，能看到它问了什么、各选项的概率和最后的结论。

## 能做什么

- **补充的话自动归到对的任务**：你在协作间里发一句没点名任务的话，它判断这是在补充哪件事，还是一件新事。
- **结果什么时候告诉你，它来拿主意**：成员的结果回来时，它判断是马上汇报，还是等其它结果一起说，免得你被一条条打断。
- **每次判断都能查**：在「上下文透镜」的「房间」页签里，能看到发给它的内容、问的问题、每个选项的概率和结论。
- **开关和分寸你来定**：在协作间设置的「自动判断」里，可以分别关掉「自动任务分类」和「自动判断汇报时机」，也能调「立即汇报阈值」。
- **它不在也不耽误**：没装、没配密钥或者一时连不上时，协作间照常工作，新消息按新任务处理，结果一到就汇报。
- **开发模式的 agent 也能用**：在 "开发模式" 里，agent 遇到需要快速拿主意的小问题，也可以直接问它。

## 安装

在 DSH 的「插件 → 添加插件」里输入下面的包名，点安装：

```
@khorsheed/dsh-dev-suite
```

快速决策会跟着「开发套件」一起装好。如果你是在其它套件里用协作间，再单独装一下 `@khorsheed/dsh-typesafe` 就行。

装好后还要填一个 TypeSafe 的 API 密钥：在开发模式下打开「设置 → 工具与技能」，找到技能 `typesafe-decide`，在「凭据配置」里填进去；也可以在 `$DSH_HOME/.env` 里写一行 `TYPESAFE_API_KEY=…`，然后重启 DSH。

## 已知限制

- 判断要联网：它会把这次判断用到的内容（你刚发的话、进行中的任务列表或成员的回报进度）发给 TypeSafe 的服务。
- 设置页里填密钥的入口只在开发模式里出现；其它模式请用 `.env` 的方式。
- 它的答案是概率，不是保证；觉得判断得不对，可以关掉对应的开关，或调高「立即汇报阈值」。

## Compatibility

需要 DSH 0.1.5-rc.1 或更新版本，已在 0.2.1-rc.1 上验证。

## 给开发者

- 它在宿主侧提供 `ctx.get('typesafe')` 服务（`judge` / `decide` / `health`，永不抛异常），模型工具 `typesafe_judge` 随包的 `./tool` 入口由模式授予；服务 API、具名问题注册表、配置项、密钥解析和实现原理都在[完整参考](https://github.com/Khorsheed/dsh-plugins/blob/main/packages/typesafe/docs/reference.md)里。
- 入口：`src/index.ts`（服务）、`src/tool.ts`（模型工具）、`src/wire.ts`（不依赖 dsh 的调用层）。协作间的调用方见 `packages/room/src/decisions.ts`。
- 隶属 [dsh-plugins](https://github.com/Khorsheed/dsh-plugins)，问题与贡献请到该仓库；变更见 [CHANGELOG.md](CHANGELOG.md)。
