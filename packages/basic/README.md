# @khorsheed/dsh-basic

[English](README.en.md) | 中文

装一个包，DSH 天天用着顺手的那些小功能就全到了：消息能改能撤，agent 改了什么看得见，后台在跑什么也看得见。

不装的时候，发错的消息改不了，agent 写了哪些文件得自己去翻，后台任务跑没跑完心里没数，上下文快满了也没人提醒。装上基础体验，这些都有人管了：你照常聊天，它在旁边把改动、任务和进度摆给你看；想要的功能不用一个个去挑，插件列表里也只多一张「基础体验」卡。

## 装完就能这样用

- 发错了一句：点「撤回」，原文回到输入框，这句和它后面的内容模型都看不到了；或者直接编辑，点「保存并重新发送」。
- 想翻回前面：点对话左边的时间轴，跳回你说过的任意一句。
- 想看 agent 改了什么：在侧栏打开它写过的文件，一次次改动可以一步步往回看。
- 让 agent「做个能点的小卡片」：它写的 HTML 会直接在对话里显示成可以操作的卡片。

## 里面有什么

- **消息工具**：编辑或撤回发出去的消息，撤回的内容不再进模型的上下文。
- **消息时间轴**：对话左边一条时间轴，点一下跳回你说过的话。
- **标题编辑**：在标题旁边直接给会话改名。
- **引用**：选中一段文字，就能「引用到当前会话」或「复制」。
- **内联卡片**：agent 写的 HTML 在对话里显示成可以操作的卡片。
- **上下文守卫**：上下文用到你设的比例，输入框旁就出现「压缩」按钮。
- **后台任务**：后台任务和子 agent 显示在输入框上方，随时能停。
- **会话产物**：预览 agent 写过、改过的文件，每次改动都能看。
- **文件列表**：浏览电脑上任意文件夹，网页、Markdown、表格和图片直接预览。
- **能力目录**：列出这个 DSH 里所有的技能和工具，以及它们各自从哪来。
- **移动端**：手机上也好用，还能接 iOS 客户端。
- **进度提醒**：任务在跑时有鲸鱼喷水动画，做完或卡住时响一声。

## 安装

在 DSH 的「插件 → 添加插件」里输入下面的包名，点安装：

```
@khorsheed/dsh-basic
```

装完不用选模式，任何会话里都能用。想要写代码、写作、学习这些专门的模式，再装对应的套件，比如 `@khorsheed/dsh-dev-suite`。

## 已知限制

- 卸载会把这十二个功能一起去掉；只想关某一个，在「基础体验」的详情页里单独关。
- 它本身不带模式，开发、写作、学习、剪辑、游戏开发、评测模式由各自的套件提供。

## Compatibility

需要 DSH 0.1.5 或更新版本，已在 0.2.1 上验证。

## 给开发者

- 命令行安装：`dsh plugin --profile web add @khorsheed/dsh-basic`，卸载把 `add` 换成 `remove`。
- 本包自己不带功能，只负责把上面十二个成员一起装上；每个成员的详细说明在它自己的 README 里：[packages/](https://github.com/Khorsheed/dsh-plugins/tree/main/packages)。
- 隶属 [dsh-plugins](https://github.com/Khorsheed/dsh-plugins)，问题与贡献请到该仓库；变更见 [CHANGELOG.md](CHANGELOG.md)。
