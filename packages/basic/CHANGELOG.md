## 0.1.0（2026-10-26）

首个公开发布：「基础体验」套件——日常用 DSH 时最顺手的十二个插件，一张卡、一次装好：

- **消息工具**：编辑或撤回已发出的消息（撤回的内容真正离开模型上下文），长消息自动折叠。
- **消息时间轴**：对话左缘的时间轴，一点跳回你说过的任意一条消息。
- **标题编辑**：在聊天标题旁就地给会话改名。
- **引用**：选中文字浮出菜单，引用进输入框或复制；从文件里引用时带上文件路径。
- **内联卡片**：在对话正文里直接显示可交互的 HTML 卡片（沙箱隔离）。
- **上下文守卫**：上下文占用超过你设的比例时，在输入框提醒你一键压缩。
- **后台任务**：在聊天框上方看后台任务和子 agent，随时停止。
- **会话产物**：预览 agent 写过、改过的文件，逐次翻看每一次改动，也能就地编辑。
- **文件列表**：浏览本机任意目录，预览 HTML、Markdown、JSON、CSV 和图片，也能就地编辑。
- **能力目录**：列出实例里所有技能和工具，标明各自从哪来。
- **移动端**：手机布局与会话首页，扫码用手机浏览器连上这台电脑上的 DSH。
- **进度提醒**：任务运行时鲸鱼喷水，完成或卡住时播提示音。

成员的取舍（发布前定下）：重启守卫和上下文透镜是开发者工具，移到「开发套件」；灵感空间和渲染抓取随「学习套件」安装；侧边对话这一波不发布；快捷键已由宿主内置，不再单独提供。
