# 变更记录

## 0.2.1（2026-10-27）

- 「连接手机」页不再在能用一键公网入口时显示「请由部署者通过 mobile.publicOrigin 或 DSH_MOBILE_PUBLIC_ORIGIN 配置……」：那句话只在读不到一键入口状态时出现，并改成「这台电脑还没有手机能访问的地址。安装 cloudflared 后可以用一键公网入口，或在配置里填一个固定的 HTTPS 地址。」配置项名字留在开发者文档（`docs/reference.md`）里。没装 cloudflared 时由原有的「本机未安装 cloudflared……」一句说明。
- 修复：在「设置 → 连接手机」里开启公网入口时，隧道建好后页面可能停在「暂时无法读取连接信息」和「请由部署者配置」的旧状态，要重新打开设置页才正常。原因是隧道写入信任主机时宿主连接会重载，正好撞上的那次读取失败；同时隧道一就绪轮询就停了，页面没再读一次。现在启动期间的后台读取失败不再报错（下一次会重试），隧道就绪后会再读一次连接信息。见 Agent Note `2026-10-27-mobile-connect-settles-after-tunnel-start`。

## 0.2.0（2026-10-26）

**不兼容变更：最低宿主提到 0.2.0-rc.2。** 0.1.x 宿主请停留在 0.1.4。

- **宿主重启不再换公网域名**：cloudflared 改由随包的 detached 守护进程（`lib/tunnel-sidecar.js`）持有，宿主重启或 deploy 后插件直接接管原隧道，已登录的手机不用重扫。守护进程在停用、cloudflared 退出或宿主停止/插件卸载 10 分钟后自行退出。
- **睡眠唤醒后快速恢复**：检测到定时器被睡眠冻结时，一次探测失败即换新域名，不受 10 分钟冷却限制。
- **失败不再停住**：连续失败后改为退避重试（最长 1 小时），写信任列表失败时保留隧道；设置页和宿主日志显示失败环节与原因（URL/token 脱敏），不再只有 `Error`。
- **连接手机改为浏览器优先**：步骤改为「相机扫码 → 浏览器打开 → 添加到主屏幕」，iOS App 降为可选补充。
- **删除 0.1.x 兼容路径**：手工 HTTPS ingress 示例与 Safari 流式兼容适配（0.2 宿主已在上游修复）、0.1.5 快照队列、列表 `current` 读取、旧输入框结构识别、open-in-app 图标匹配与 `[data-composer-stats]` 样式。
- **README 重写**：按「相机扫码 → 浏览器打开 → 添加到主屏幕」的新流程改为大白话说明。

## 0.1.4（2026-10-22）

移动端面板整编（2026-10-02 自适应面板波）与一波活体反馈修复；适配宿主 0.2.1 线。

- **全宽移动面板取代桌面标签栏**：新建会话旁新增统一面板入口，打开后全宽展示宿主右栏面板——独立的 52px 面板导航承载返回键、可横向滚动的具名页签与「添加」，关闭按钮归入活动页签；仅展示活动栏（含浮窗），不改写宿主保存的分栏与浮窗位置。面板内容保持挂载，选择、草稿与滚动状态不丢，返回恢复原控件焦点；宿主把右列收起为零宽时面板仍锚定整个 frame 全宽展开。
- **页签改扁平下划线样式**：等高纯文字页签，活动页签加粗并以强调色下划线托住文字与关闭按钮（桌面式凸起盒子在手机上读作异物）；关闭点击区收紧为 24px 宽、占满导航高度。触屏设备上抬高面板字号 token。
- **官方侧栏抽屉只在明确请求时打开**（设置 → 工作区）：重连后宿主自行展开的桌面抽屉会被收回，其遮罩不再以灰色条带盖住打开中的面板。
- **触屏/触控笔长按归还原生文字选择**：不再用同一手势弹出竞争的消息弹窗，原有消息动作栏保留可用。
- **性能**：流式消息增量不再触发整页布局与面板扫描（观察器忽略已验证历史槽位的内部变化）；Room 成员列表未变化时保留原快照，不再重复发通知或触发兼容刷新。
- **适配宿主 0.2.1 线**：`@deepseek-ai/dsh-*` peer 区间追加 `^0.2.1-rc.1`（`^0.2.0-rc.1` 在 npm/pnpm 严格解析下不覆盖 0.2.1 预发布三元组）；宿主 0.2.1 移除 invariants 体系，随包 invariant 伴生退役、兼容判定改由 package.json `engines.dsh` 声明。对 0.2.1-rc.1 树全量构建+测试通过；真机/网络验收矩阵完成前仍不声明 verifiedHost。
