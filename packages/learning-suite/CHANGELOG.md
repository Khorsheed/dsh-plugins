# 变更记录

## 0.1.0（2026-10-26）

首个公开发布：「学习套件」——学习模式（`dsh-learning` 预设）和它用到的插件，一次装好。装完开一个「学习模式」的会话，告诉教练你想读什么书：

- **图书馆**：让 agent 当读书教练——排学习路线、拍一页记笔记、学完一站就测、错题订正对了才算掌握。
- **灵感空间**：订阅 RSS、保存文章链接、视频与播客，在灵感墙上读正文、划词记笔记、带着笔记讨论、让 agent 考考你；页签只在授予它的模式里出现。
- **本机转写**：灵感空间给没字幕的视频和播客出文稿时，在这台电脑上转写并分出说话人。
- **渲染抓取**：网站拦下普通抓取、或内容要等脚本加载时，用后台浏览器把页面完整打开一遍，把正文带回灵感空间。

学习模式的预设行由本包自带（原 `@khorsheed/dsh-presets` 已退役）；npm 包名为 `@khorsheed/dsh-learning-suite`（首发前由 `@khorsheed/dsh-learning` 改名，旧名从未发布），预设 id 与行 id 不受影响。灵感画布这一波不发布，套件不带它；灵感空间的「同步到画布」在没装画布时自动隐藏。
