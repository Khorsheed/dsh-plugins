# 变更记录

## 0.1.0（未发布）

首个版本——剪辑台 M1：节目与工程、设置三层、按路径导入、画面按声音对齐、本机分人与声纹认人、Paraformer 转写与标点、文稿粗剪（点句剪切、语气词/停顿/重复扫描提议）、导出 MP3 / MP4 / SRT / TXT；右栏「剪辑」面板（素材 / 文稿 / 导出 / 设置）与 `./tool` 入口的 `video_*` 工具和 `video-studio` 技能。设计见 Agent Note `2026-10-06-video-studio-podcast-editing`。

文稿 tab 的边听边剪：底部播放器按剪后成片或原声无缝播放（Web Audio 调度宿主按需回读的 PCM），当前段落与词跟随高亮、滚动自动加载；剪切按来源区分（我剪的 / 模型剪的，可过滤）；拖选任意几个字可剪掉或改字，查找栏可逐处或全文替换；模型的 `fix_text` / `cut_keyword` 改字与关键词剪切一律作为提议组等 ✓。改字只影响文字与字幕，不动音频。见 Agent Note `2026-10-10-video-studio-listen-and-correct`。

右栏「剪辑」tab 改为按会话 preset 自隐：只在剪辑模式（组合含 `@khorsheed/dsh-video-studio/tool` 行）出现，标准模式等会话隐藏，已开残留 tab 渲染宿主 tab.unavailable 兜底；所有读不到判据的路径 fail-open。剪辑模式 preset 同步改为独立组合（去掉 shell 与 web 行）。见 `2026-10-12-video-studio-preset-gate`。

M1 收尾（见 `2026-10-11-video-studio-m1-polish`）：文稿 tab 双视图——默认「成片」（剪掉的内容消失、成片时间码、点句播放、撤销浮条），「原始」保留划线标记与来源过滤；查找替换默认跳过已剪内容。垫乐混音进 MP3/MP4（循环、闪避）。导出 30 天后清理工程缓存。多段连续录音：导入勾选「连续录制」按顺序拼接成一条参考轴，转写/播放/导出无感，画面逐段独立对齐，文稿在接缝处画分隔条。

工具面收敛为 5 个：`video_scan` 折进 `video_propose_edit scan`；技能新增「校稿」一步——模型通读文稿，用常识把同音错字、专名作为 `fix_text` 提议组交给用户 ✓。文稿 tab 交互：拖选弹出浮动菜单（▶ / 剪掉 / 恢复 / 改字…），「待决」更名「待确认」，删除线与停顿徽章视觉降噪。

查找栏重做（见 `2026-10-18-video-studio-find-nav`）：吸顶不随正文滚动消失；命中逐个跳转（↑/↓、Enter/Shift+Enter、「3/12 处」计数、当前命中实心高亮并滚动居中，命中超出分页窗口自动扩页）；「改字…」把选区带进查找栏、预填替换词并定位到该处，「替换当前」只改这一处、「全部替换」全文生效；删除「只看这些」过滤（成片视图下不可见也关不掉）与「存进节目，以后自动改」（默认勾选、无管理界面的跨期静默规则）。

修复：新建工程名称为空时禁止创建（此前静默落为「未命名工程」，且在「新节目」名称框按 Enter 会隐式提交整个表单）；service 层已有的 `renameProject` 接通 Remote 与面板——「设置 → 这期」顶部可改工程名；名称占位符改为「例：…」不再像已填内容。见 `2026-10-13-video-studio-project-rename`。

素材导入新增「选择文件夹…」：复用宿主原生目录选择器（`remote.directoryPicker`，local-files 同款 ctx.get 降级模式）选中文件夹后，面板列出其中的音视频文件（名称排序、大小、类型圆点）勾选导入；只在页面从宿主机本机打开时显示，远程访问隐藏，宿主无选择器时按取消处理。素材 tab 同步按用户旅程重排：空工程是居中的引导卡（大按钮选文件夹，手动输入路径折叠为一个链接），已有素材后收起为一行紧凑按钮，文本框不再默认占位。见 `2026-10-13-video-studio-folder-pick-import`。
