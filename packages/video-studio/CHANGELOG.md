# 变更记录

## 0.1.0（2026-10-26）

首个公开发布：剪辑——剪播客和对谈，录音变成文稿，删一句话就剪掉一段，嗯嗯啊啊和长停顿 agent 帮你找。随「剪辑套件」安装，右栏「剪辑」页只在剪辑模式的会话里出现。

- **节目与工程**：一个节目下多期工程，片头片尾、音量、字幕样式和常驻成员的声音存在节目里，新一期直接沿用；工程可改名。
- **导入素材**：选文件夹（本机打开页面时用宿主的目录选择器）或填路径；多段连续录音可按顺序拼成一条，转写、播放、导出都无感；画面按声音自动对齐。
- **一条混录也能分人**：本机分出几个声音，给新声音起一次名字，同一档节目下次自动认出（分人与转写由「本机转写」插件完成，录音不上传）。
- **删字就是剪音频**：文稿默认显示「成片」（剪掉的消失、成片时间码、点句播放、可撤销），「原始」视图保留划线与来源（我剪的 / 模型剪的）；原始录音从不改动。
- **边听边剪**：底部播放器听剪后成片或原声，当前句和词跟随高亮；拖选几个字可剪掉或改字，改字只影响文字与字幕、不动音频。
- **查找替换**：查找栏吸顶，逐处跳转并计数，可只替换当前一处或全部替换；默认跳过已剪内容。
- **啰嗦的地方 agent 来找**：语气词、长停顿（是缩短，不是删光）、重复，以及同音错字和专名校对，都作为提议组等你点「采纳」。「AI 帮改」把请求填进会话输入框，你补一句再发。
- **一键导出**：MP3、MP4（可混入循环垫乐并自动闪避）、SRT、TXT；导出 30 天后自动清理工程缓存。

需要本机装有 `ffmpeg`；第一次转写要先下载语音模型。
