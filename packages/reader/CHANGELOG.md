# 变更记录

## 未发布

- **订阅源和文章不再被新版搜索 API 开关弄坏**：宿主 0.2.1-rc.2 起，网页搜索设置页的「启用新版 Web 搜索 API」会把抓取一起切到 DeepSeek Fetch API（返回 Markdown），订阅源会被当成网页、文章抽不出正文。现在阅读器在官方 web 服务上用自己持有的官方 HTTP 抓取提供方实例抓取，拿到的始终是原始文档；没装提供方包时照旧走 `ctx.web.fetch`。新增配置 `fetchLimits`（`maxResponseBytes` / `maxBodyChars` / `timeoutMs` / `maxRedirects`），抬过 `web-fetch-http` 行上限的部署改配这里。见 Agent Note `2026-10-24-reader-own-http-fetch-provider`。

## 0.3.1（2026-10-26）

- 修复：重新转写一篇之前翻译过的稿子时，转写进行中每次正文刷新都会重新铺一遍翻译（提示条反复出现）；现在转写中不恢复翻译，转完后恢复一次。
- **让 Agent 润色译文**：地球菜单（没有本机翻译时在标题栏）一键把润色请求填进输入框；模型用 `reader_read` 分批读原文、从原文整段翻译，用新工具 `reader_translate`（每行「¶12：译文」）分批写回，直到全文完成。面板每 5 秒刷新，润色版逐段替换机翻显示（未开机翻时与原文对照），段尾「✦ 润色」点了这一段改回机翻，顶部有进度与「看机翻」（不记住）；中途停了给「继续润色剩下的 N 段」。润色存在宿主（`polish/`），跟着原文：说话人改名保留，重新转写作废。
- **转写在重启后续上**：任务记录存在它的临时目录里（`job.json` + 已转段落 `segments.json`），实例重启后自动续跑——音频不重下，转写从断点接着来，已存稿的直接重跑分说话人。
- **转写稿分说话人**：本机转写出稿后在后台接着区分说话人——先抽 24 段音色比对（约 1 秒），只有一个人就到此为止；多人才跑完整分人，按时间把每句话归给说话人、换人处分段，段落带说话人颜色，换人的那段开头标名字；页签上方的图例点名字可改名（整期替换，存在宿主上）；讨论、考考我读到的原文写成「[mm:ss] 嘉宾：…」。分人中来源行显示「正在区分说话人…」。
- **详情页减负**：删掉底部「当前会话草稿」预览和「引用 / 记笔记 / 发到侧边对话」一行（划词菜单里有引用与记笔记），文末只留标签；「让Agent考考我」从文末整行大按钮改为页签行右侧的「考考我」小按钮，文末留一行文字链接。添加对话框的「抓取」在输入框为空（含保存成功后清空）时置灰，抓取中显示「抓取中…」。
- **切回灵感空间不再重载**：右栏切到别的页签再切回，宿主会卸载面板；现在页面内存里留着解析好的卡片墙，切回来立即显示，只重新读取抓取时间变了的源（刷新、添加源照旧全量重读）；卡片墙翻译跳过已有译文的卡片，不再重新翻译。
- **转写稿断句**：引擎按真实停顿切块后，一句话不再被拆进两段；没有句号的长句超过 20 秒遇逗号、30 秒遇停顿即断，最长 45 秒；小于 20 MB 的模型补下载不再询问。已有转写稿点「重新转写」生效。
- **视频与音频打磨**：卡片与文章卡等高，右侧封面 + 转写状态药丸（新 Remote `mediaStates`，有卡在转写时每 3 秒刷新）；详情的控制收成一行（B 站说明收进 ⓘ），页签改叫「转写稿」，时间排进左侧一栏并带 ▶ 与一次性提示；视频往下读时收成迷你条（同一个画面缩小，YouTube 可暂停、显示时间与进度）；跟随在手动滚动后停止，「回到正在播放」接上（去掉「跟随」开关）；转写中地球置灰，「转完自动翻译」全局勾选（默认不勾），外语转写稿以对照视图自动翻译。见 Agent Note `2026-10-20-reader-media-polish`。
- **本机转写**：没有字幕的视频和音频（B 站多数视频、播客、小宇宙）打开详情页即在本机转写，经可选的「本机转写」插件（`transcribe` 服务，探测；没装时如实提示）；音轨临时下载（yt-dlp 取最小音频格式 / curl 取音频直链）转完即删；转完的部分边转边显示、可读可记，完成后存为正文并标「来源：本机转写」；排队中离开撤出队列、在转的转完，「字幕」关掉或「取消」即停止；首次下载模型确认一次；订阅刷新不转写。见 Agent Note `2026-10-20-reader-local-transcription`。
- **视频与音频**：YouTube / B 站视频、播客 RSS、小宇宙单集与节目进入灵感空间，类型按每条内容判断；视频以平台字幕为正文（合并成带时间的段落、时间标记可点、当前段高亮跟随、「字幕」开关、播放位置记忆），笔记带时间、`reader_read` 带 `[mm:ss]`；卡片标类型与时长，筛选加视频 / 音频。宿主经自管的独立版 `yt-dlp` 取字幕与频道列表（YouTube 自家频道 RSS 已 404），小宇宙节目页转成 RSS。新增配置 `ytdlpPath`、Remote `mediaTranscript`、状态文件 `media.json` 与 `bin/`。
- **笔记**：划词「记笔记」（挂进 quote 的选区菜单，另有详情页兜底按钮），摘抄 + 评论存进独立的 `notes.json`；在译文里划的存原文并附译文；正文以 CSS 自定义高亮标出记过的句子；详情页「正文 / 笔记」切换，笔记可编辑、删除、跳回原文。
- **带着笔记讨论**：选中的笔记合入会话草稿（不覆盖、不发送），文章记下讨论过它的会话，可回到会话。
- **`reader_read` 工具**（新组合入口 `./tool`，patch 新增 `reader-tool` 行，全会话可见）：读最近打开或指定的文章，正文按 ¶ 编号分页、附读者笔记；正文来自浏览器打开文章时交给宿主的原文快照（`snapshots/`，无笔记的文章只留最近 30 篇）。
- **结论写回与讨论笔记**：`reader_note` 工具（`op=conclusion` 挂在某条笔记下，`op=discussion` 记一条讨论笔记，`kind=check` 为考考我；支持只靠 text 的纯文本写法）；读者可追加、改写、删除结论，删除讨论笔记；笔记页显示时每 5 秒重读一次，Agent 写回的内容自动出现。
- **让Agent考考我**：文末与笔记页的按钮把考考我请求填进输入框（附约定）；`reader` 技能写明一次问一组、答完只讲没到位的、记成考考我笔记、不打分。
- **同步到画布**：装了灵感画布时，笔记 / 讨论笔记可落成正式灵感卡（经画布的 `ctx.canvasInbox`，探测，缺席即隐藏），记住上次的画布，可带讨论结论，`markSynced` 记下落到哪张卡。画布这一波不发布，没装画布时这个按钮不出现。
- **按模式显隐**：右栏页签按 `./tool` 行双查自隐（画布同款）；灵感空间移出基础体验合集，改随「学习套件」安装（写作套件这一波不发布），工具与页签只在授予它的模式的会话里出现。
- 新增可选 peer：`@deepseek-ai/dsh-tools`、`@deepseek-ai/dsh-agent`。
- **README 重写**：改为大白话说明，开头不再以「同步到画布」打头，安装只写学习套件。

## 0.3.0（2026-09-30）

- **CORP 拦截图救回**：以 `cross-origin-resource-policy: same-origin` 供图的站点（如 claude.dev）会让浏览器跨域 `<img>` 必挂，只有宿主进程抓取能绕过。新增 `fetchImage` Remote——只重抓已经加载失败的图片（公网地址校验钉在 DNS 答案上、逐跳重定向再校验、限 `image/*` + 8MiB + 15s、32MiB LRU），阅读面板把这些图改指 data: URI。健康图片从不经过代理；旧版宿主下图片维持 broken
