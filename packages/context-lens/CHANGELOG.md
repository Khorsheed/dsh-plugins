# 变更记录

## 0.1.1（2026-10-27）

- **提问卡片**：agent 用提问工具问你的问题，在透镜里显示成和对话里一样的问题卡片，看得出问了什么、你选了什么。
- **成员的请求能看全**：协作间成员的模型请求体在读取时重建，不再缺内容；回填拿不到东西时说明原因。
- 会话地图的柱子按第 95 百分位缩放，个别超大的一轮不再把其他轮压成一条线；非 JSON 的工具参数保持卡片缩进；面板底色和侧栏一致。

## 0.1.0（2026-10-26）

首个公开发布：上下文透镜——点一下任意一轮对话，就能看到模型这一轮到底收到了什么、token 花在哪、时间耗在哪。随「开发套件」和「多Agent协作」安装。

- **从对话直接打开**：每轮回答下面的「请求明细」图标跳到这一轮，会话顶部的图标打开最新一轮；对话还没渲染到的旧轮次也能跳过去，「回到最新」一键回底。
- **会话地图**：面板顶部是整段会话的轮次地图（有其它 agent 参与的轮次带标记），下面平铺这一轮的参与者——主对话、外部 agent、子 agent、压缩；外部 agent 的页签跨轮保留。长会话按 30 轮一窗加载，可往前往后翻。
- **看清请求里装了什么**：系统提示、工具定义、历史和本次新增分块显示，系统提示每一段标出来源，可展开原文；「只看重复」挑出重复塞进去的内容，只计多出来的副本。
- **知道缓存为什么断**：真实的缓存命中与未命中（含缓存写入），和上一次请求的差异精确到字，并逐条列出每一处变化及其背后的宿主事件（替换、压缩、裁剪）。
- **看时间花在哪**：总耗时拆成模型、工具执行和空档，各 agent 独立泳道，工具表可排序；子 agent 的时间不在主对话里重复计算。
- **协作间看得清**：协调者交接后，人发给成员的每次派活单独成一轮；Codex / Claude Code / Kimi 这类 CLI 成员的会话按它们的日志重建，一次调用算一次请求、从上一个事件计时；协作间发言卡片的明细按钮直接定位到那位成员的那一轮；「房间」页签列出协作间自动判断的每次模型调用（场景、概率、输入输出 token、延迟、发出的状态与得到的答案）。
- **装之前的对话也能看**：打开时从会话日志补出插件装上之前的轮次，遵守上下文替换与压缩。
- **只看不改**：只读监听宿主的三条请求接缝，从不改写发给模型的请求；数据只放在内存里（有总量上限，最旧的回溯先让位）。

技术面：Remote 动词 `listTurns` / `getTurn` / `getRequest` / `getTurnTiming` / `getSessionTrend` / `loadTurns`，可带 `filter.scopes` 供可信服务端按授权过滤；需要宿主 0.1.5-rc.1 起，turn 动作行入口需 0.1.7-rc.1 起（旧宿主只有会话头部入口）。本包由仓内的 request-inspector 改名而来，`requestInspector` 服务与 Remote 命名空间保持兼容；迁移时替换依赖与行，不要两个同时挂载。
