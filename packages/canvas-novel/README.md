和 agent 一起写长篇连载：写到第一百章，它还记得人物设定、知道上次写到哪、没忘了埋下的伏笔。

和模型写长篇，最怕写着写着它就忘了：人物性格前后不一，伏笔埋了没人收，每开一次新对话都得把背景重新贴一遍。长篇小说是灵感画布的一种体裁：一部作品就是一块画布，人物、世界观、伏笔、关系、写作原则都是画布上的卡片。你和 agent 先定大纲，再一章一章地定计划、写正文；每写完一章，agent 回头对一次账，把这一章发生的事记回卡片上。下次换个会话接着写，它从卡片里读到的就是这部书现在的样子。

## 能做什么

- **一部作品一块画布**：新建画布时体裁选「长篇小说」，人物、体系、地点、势力、物种与道具、伏笔、关系、写作原则几类卡片就备好了，每类都有现成的栏目可填。
- **设定连成一个世界**：地点写明在哪个更大的地方里，势力写明据点，人物写明属于哪个势力、常在哪里；打开任何一张卡，都能看到它属于哪里、下面有什么、谁和它有关、出现在哪几章。旧作品可以让 agent 一次整理到新的分类里，整理前会先给你看整理结果。
- **先定大纲再动笔**：和 agent 聊清楚主线、主角、结局方向和篇幅，它在「总览」页起草一页纸大纲和分卷，你点「采用」才算数，之后随时能改；总览下面是整个世界观的地图。

<img src="https://raw.githubusercontent.com/Khorsheed/dsh-basic/main/docs/screenshots/canvas-novel-planning.png" width="560" alt="规划页：顶部全书进度，一页纸大纲，虚线框里是 agent 的大纲提议，带「采用 / 不采用」，下面是按卷排列的章节路线">

- **聊到的设定直接成卡**：聊天里定下的人物和世界设定，agent 会直接记成卡片；不对就改，同名的人物只会有一张。
- **先想好接下来发生什么**：「时间轴」左边是已经发生的事，按故事里的先后排；右边是将要发生的事——你预设的情节、人物的打算、迟早会来的后果、伏笔的揭晓——按优先级分成临近、积压、就绪、饱和、搁置，每件都写着为什么。
- **每章先看计划再开写**：规划下一章时，agent 从时间轴挑出该推进的几件事，列出这一章的目标字数、情节、冲突、伏笔和出场人物；你可以在「章节」页把某件事设为优先推进或本章屏蔽。看完计划点「按计划开写」，它就动笔。
- **自己也能写**：章节页可以直接编辑正文，也可以从顶部或列表底部的「新建」菜单选自己写或让 Agent 规划，手机上也行；章号自动取当前最大章号的下一章。写累了点正文末尾的接力入口，当前内容会先保存，续写请求填进对话，你改好再发，不会自动发送；Agent 默认从末尾续写，确需调整前文时会说明改了哪里和原因。重新打开会回到上次章节和编辑位置，未保存的草稿也还在这台设备上。随手想到的一场戏、一句对白记在「灵感」页，排进时间轴后，写到那件事时原文会一起带上。
- **集中整理本章想法**：划选正文后在引用菜单点「记录想法」；整章问题直接在对话里说即可。点章节顶部「想法」按需展开列表，浮层始终贴在按钮下方，点击空白或按 Escape 收起。攒成一批后点「填入对话」，完整原文和想法会进入当前会话的输入框，你改好再发，不会自动发送；上一批还没完成时也能整理下一批。Agent 完成正文修改后，对应批次自动归档；只讨论、写作失败或正文版本冲突都不会归档。
- **已有小说一键导入**：在「章节」页点「导入」，一次选多个 TXT 或 Markdown 文档；在宿主本机也可以点「导入文件夹」，递归读取整个目录。文件按名称或相对路径自然排序，识别「第…章」「Chapter…」等独立标题自动拆章。检查预览并确认后，正文进入工作区；导入不会发送或填写对账消息，你可以复制请求到合适的对话。
- **删错章节也能找回来**：在章节页多选后删除，确认框会列出正文、相关记忆和可级联清理的卡片；仍被其他章节使用的设定默认保留。删除后进入回收站，可逐章恢复或按占用大小彻底清理；恢复正文和计划后重新对账。
- **正文就在你的工作区里**：每一章是工作区里的一个 Markdown 文件，任何编辑器都能打开。
- **写完对一次账**：在对话里说「对账第 3 章」，agent 读完正文，把这章发生的事记上时间轴，把人物经历、他们新相信的事和打算、关系变化、伏笔进展记回卡片。
- **一眼看清整本书**：「时间轴」切到「按章节」，按章节摊开伏笔的埋下和揭晓、人物关系的起伏和每个人的经历；「章节」页按卷排目录，带阅读器，点「继续写」接着往下写。

## 安装

在 DSH 的「插件 → 添加插件」里输入下面的包名，点安装：

```
@khorsheed/dsh-writing-suite
```

长篇小说会跟着「写作套件」一起装好，灵感画布也在里面。装完开一个新会话，选「写作模式」，对 agent 说「我想写一部长篇，新建一块长篇小说画布」。

它只在写作模式的会话里出现，在其它模式里看不到是正常的。

## 已知限制

- 章节正文要存进画布挂着的工作区；存不进去，这一章就不会登记。
- Word（.doc/.docx）请先另存为 UTF-8 TXT 或 Markdown；没有可识别章节标题的文档按一章导入。
- 文件夹入口只在宿主本机显示，远程页面请多选文件。文件夹最多递归 32 层、读取 500 份共 100MB 的支持文档，超限会在预览中标明。
- 不是从当前会话打开的画布只能看，不能处理待审。
- 旧插件 story-bible 的数据不会迁移过来。

## Compatibility

需要 DSH 0.2.0-rc.2 或更新版本，已在 0.2.1-rc.5 上验证。划选评论只从可选的「引用任意内容」菜单进入；想法列表锚定在章节顶部按钮下方，点击空白或按 Escape 收起。多个开放批次彼此独立，只在真实发送、可验证的同章写入和轮次正常结束同时成立时归档。

## 给开发者

- 入口：`src/index.ts`（体裁与写作引擎）、`src/agent.ts`（agent 用的小说工具）、`src/client/index.ts`（画布里的各页）。
- 可以单独安装（`dsh plugin --profile web add @khorsheed/dsh-canvas @khorsheed/dsh-canvas-novel`），但必须和灵感画布一起装；没有画布时它什么也不做，也不会报错。
- 关系卡怎么打分见[关系评估标准](https://github.com/Khorsheed/dsh-plugins/blob/main/packages/canvas-novel/docs/relation-criteria.md)；隶属 [dsh-plugins](https://github.com/Khorsheed/dsh-plugins)，变更见 [CHANGELOG.md](CHANGELOG.md)。
