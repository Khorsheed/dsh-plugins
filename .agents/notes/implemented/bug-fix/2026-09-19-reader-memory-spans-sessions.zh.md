# Agent Note：读者「读到哪」属于页面，不属于会话

Status: implemented

## Problem

读者反馈：在一个对话里读了（并翻译了）一篇文章，切到另一个对话打开灵感空间，里面什么都没有——没有打开的正文，也没有译文。

面板里那份「读者刚才在哪」的记忆（见上一条 note）是按 `sessionId` 存的。而面板是**按 dsh 会话挂载**的，所以那个键意味着每个对话都从灵感墙的默认状态开始：要重新找到那篇文章、阅读位置没了、地球是灭的所以译文要再付一次代价——尽管页面级的翻译会话缓存（模块级、本来就是全页面共享）本可以免费恢复，尽管正文早就缓存好了。

有一点要分开说，因为反馈里也提到了「内容的缓存」：**正文从来不是按会话存的**。它在部署的 `state.json` 里、按条目 id 索引（`$DSH_HOME/state/dsh-reader/state.json` 加 `bodies/`），任何会话读到的都是同一份；在验收实例上实测，一份文档里躺着来自很多会话的 106 条缓存正文。真正按会话隔离的只是面板的**视图**：哪一篇打开着、读者滚到了哪、墙收窄成什么样、地球亮不亮。

## Decision

- **整个页面共用一个记忆桶。** `client/session.ts` 彻底去掉 `sessionId` 参数：`readSession()` / `patchSession(patch)` / `rememberScroll(entryId, top)` / `rememberTranslation(entryId, view, source)` / `forgetTranslation(entryId)`。这个页面挂载的任何面板——包括属于另一个 dsh 会话的——恢复的都是同一个位置：同一篇打开的正文、同一个阅读位置、同样的墙收窄、同样的译文（自动恢复，因为翻译会话缓存是全页面的，已存在的会话不需要用户手势）。
- **会话 id 只留给真正关于「这个对话」的动作**：读取/合并对话草稿，以及引用到侧边对话时的 `contextKey`。这些由 `client/index.ts` 注入的面（本来就闭包了会话）持有，读者位置相关的记忆一律不经过它。
- **按会话记住的 LRU 上限随键一起消失。** 现在只有一个快照；它的按条目表（阅读位置、翻译记录）随读者在墙上真正碰过的条目增长，`cardTranslations` 随墙上翻过的卡片增长——都由屏幕上的条目数封顶。
- **依旧不落盘。** `state.json` 不合适只有一个原因：单是地球记录（视图 + 源语言）可以落盘，但译文不能，刷新之后又没有可用于驱动的翻译会话（没有用户手势），所以落盘的记录会是**空的**；而代价是把「哪些文章被翻成了哪种语言」写到磁盘上，换不到用户看得见的好处。读者报的这个场景，页面级记忆已经完整覆盖，之前那条「译文不离开页面」的规则也依然成立。真正扛过刷新的两样东西是宿主状态、从宿主读：缓存正文与「最近阅读」列表。

## Alternatives considered

**保持按会话，同时把翻译记录按条目落盘到 `state.json`。** 能扛重启，但记录本身重建不了翻译会话，所以恢复出来的面板地球还是灭的；而且为了一个用户从没要求的好处，把翻译元数据写到了磁盘上。
**保持按会话，再给一个「回到刚才那篇」的入口。** 读者的预期是「同一个页面里的同一面墙本来就是同一个地方」；用一个按钮回到那儿，是这件事更差的版本。
**`sessionStorage`（同时扛刷新和跨会话）。** 之前已否决，现在依然否决：刷新是一次新的到访，译文不能进任何存储。
**把灵感空间 tab 的内容也按会话隔离**（每个对话一面墙）。直接否决：源、正文、最近阅读都是部署级状态，为每个对话各存一份会和这个包里其他所有设计相矛盾。

## Consequences

- 切换会话不再重置灵感空间。墙、打开的正文、阅读位置、译文全都带过去；只有对话草稿和「引用到侧边对话」还取决于当前是哪个会话。
- 有一条假设现在是承重的：**宿主同一时刻只渲染一个侧栏**（`RightbarRoot` 只在没有其他活动主面板时渲染），所以只有一个面板写这个桶。如果哪天两个面板同时挂载，这个桶就是「后写覆盖」——而这本来就是一个共享记忆的定义行为。
- `tests/session.spec.ts` 变小了：「两个会话互不串台」和「12 个会话的 LRU」两个用例描述的是已经不存在的 API。跨会话这件事改为在**能观察到它的地方**断言：`tests/ReaderPane.client.spec.tsx` 用**两个不同的会话 id** 挂载面板两次，要求文章和它的译文不用点击就已经在那里。
- spec 的 `afterEach` 改成 `forgetSession()`（无参）——记忆现在是全页面的，每个用例否则都会继承上一个用例的位置。

## Testing

`packages/dsh-reader` 共 253 个测试（两个按会话的用例删掉，新增一个跨会话用例）：

- `tests/ReaderPane.client.spec.tsx`（+1）：为 `session-a` 挂载的面板打开一篇英文文章并点亮地球；卸载后为 `session-b` 挂载面板，文章已经打开、译文已经在屏幕上，这一次既没点卡片也没点地球。
- `tests/session.spec.ts`：快照的合并语义、阅读位置、翻译记录（含「原文」会清掉记录）、按语言对索引的翻译会话缓存——现在全都没有会话参数。
