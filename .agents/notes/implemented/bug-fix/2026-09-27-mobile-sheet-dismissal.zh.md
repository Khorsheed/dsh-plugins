# Agent Note: 移动端弹层关闭与当前标题锚点

Status: implemented

## 问题

Room 邀请及编辑表单已有鼠标点击遮罩关闭，但没有移动端拖动关闭，因此移动端把手暗示了一项未实现的交互。另外，0.1.7 会话栏把当前层级标题从禁用按钮改为 span，移动端旧锚点不再隐藏重复标题。这与 Agent Team 是否显示无关。

## 决策

仅在移动模式下，为已识别的 Room 遮罩委托处理触摸。弹层滚动到顶部时，从顶部 96 像素的标题及把手区域明确向下拖动 72 像素即可关闭。点击外侧遮罩也委托给原有 mousedown 关闭处理器。表单滚动、输入框、模型折叠控件、横向或短距离手势、文字选择、嵌套原生对话框均保留原行为。取消拖动或卸载时恢复内联变换；表单在途状态和回调仍归 Room 管理，不替换 Room 实现或接口。

当前标题锚点同时接受旧版禁用按钮和紧邻官方 lineage 槽位之前的新版不可交互文本 span。已知子代理数量控件保持可用，可点击祖先及未知层级控件均保留。桌面样式与动作不变。

## 考虑过的替代方案

全局派发 Escape 可能关闭无关菜单或弹层；直接移除 React 节点会绕开属主状态；整张表单拦截向下手势会干扰滚动编辑；隐藏整行标题栏会移除插件动作。因此复用原遮罩关闭动作，并严格识别不可交互标题锚点。

## 后果

只有弹层顶部支持拖动关闭，正文仍负责滚动。属主当前允许提交期间取消，本适配遵循该规则。锚点变化需要后续兼容审查，无法识别表单或标题结构时保留原界面。回归测试覆盖外侧点击、拖动阈值、滚动及输入框、卸载、新版标题结构及子代理数量入口。构建与包测试通过，部署后仍需 iPhone 真机手势验收。
