# Agent Note: DSH 委派回答不混入推理内容

Status: implemented

## 问题

Room 隔离验收中出现推理文本与最终回答拼接的回报。DSH live 镜像有意在会话中保留两个内容块，但纯文本进度串同时被复用为委派结果。

## 决策

镜像消息的纯文本只包含 text 块。原生 reasoning 连同用量和工具事件完整保留在成员会话。Room 发言和关联回报因此取得可见回答，不把推理变成回答内容。

## 考虑过的替代方案

**在 Room 剥离推理。** 到达 Room 时两类内容已扁平化成同一个字符串，无法可靠拆开；provider 仍持有原生类型。

## 影响

进度文本与委派结果对可见回答保持一致。既有会话不变，修复不重写此前记录的 Room 发言。原生流式仍需独立内容块展示及浏览器时延验证。

## 测试

DSH 测试覆盖 reasoning/text 混合事件、原样保留会话及实际 live-driver 轮次仅返回回答。缺陷已在隔离浏览器观察到；修正后的浏览器复测仍待重启。
