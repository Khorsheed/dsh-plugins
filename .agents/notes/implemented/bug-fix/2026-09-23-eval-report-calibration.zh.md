# Agent Note：评测报告的结论校准——第五条校验「判定覆盖一致」，置信区间按题数给

Status: implemented

## 问题

pilot-d-preset 的报告从每组各跑一次的一道题里印出了 `mean Δ = 4, 95% CI [4, 4]`。两处同时出错。其一，两侧的判定来源不同：dsh-full 格两次判官调用都失败（bundle 里有两条 `judge-parse-failed`），只剩探针的脚本判定；dsh-lean 格有判官的 llm-draft。逐判据合并（T54）各取各侧最高一层，于是差值是拿一侧的纯脚本分减另一侧的判官分，再把这个落差当成预设之间的差异报出来。其二，区间只有一个区组：一道题上的自助法只能反复抽到这一道题，`[4, 4]` 声称零不确定性，而实际上关于不确定性什么信息都没有。`comparePair` 在 n < 3 时拒排名，却照样打印区间，页面只要 `ci` 非空就渲染。

## 决定

**第五条有效性校验「判定覆盖一致」（`verdict-coverage`）。** 每个比较的配对格（同题、同次），每条判据要么两侧都有「已判」判定（human-final 或 llm-draft），要么都没有。一侧只有脚本判定或什么都没有即不成立。人只改一条判据不触发——人的判定本来就算已判。这条的状态是所有配对的合取；明细逐条写出缺口，该格判官调用全部失败（「判官缺席」）时，失败原因取自 bundle 里本来就有的 `judge-parse-failed` 注解——不需要新增注解。

**覆盖不一致只降级这一对，不闸整节。** 前四条仍决定整个比较节开不开，`comparisonAllowed` 与判据表的闸也只看前四条。覆盖缺口保留这一对的逐题事实（得分、逐次差值），去掉区间与名次；`rankReason` 写「判定覆盖不一致：<题> 的 <判据…> 在 <组> 没有判官 / 人的判定（判官缺席 / 仅脚本）」。页面上「比较节未开」的横幅只数前四条。

**置信区间按题数给。** 设 k 为至少有一个配对差值的题数：k < 3 → 不给区间，`ciWithheld: {tasksWithDelta: k}`，页面与 summary 写「只有 k 道题有差值，给不出区间」；k ≥ 3 → 照旧计算，n < 3 时标 `ciAdvisory`，页面写「仅供参考，未达排名条件（每题需跑满 3 次）」。排名门槛不变：n ≥ 3 且区间不含 0。

真实 pilot-d bundle 上，summary 现在显示第五条 ❌，明细为「P0-placeholder 第 1 次的 B2、D1、D2、D3、D4 在 dsh-full 没有判官 / 人的判定——判官缺席（判官调用 2 次均失败：judge delegation ended with stopReason "error"）」，没有区间行，名次判定为「判定覆盖不一致：…（判官缺席）」。

## 考虑过的替代方案

**区间按次数（n）而不是题数给。** 否决。自助法以题为区组重采样，区间要回答的是「换一批同类的题，这个平均值会不会动」——这是关于题数的陈述，不是关于每题重跑了几次。一道题跑三次仍然只有一个区组，得到的仍是退化的 `[x, x]`。反过来，很多题各跑一次的实验很常见，按 n 设闸就永远不给它区间，尽管它有真实的题间离散——所以 k ≥ 3、n < 3 的区间标为「仅供参考」印出来，而不是藏起来。名次仍看 n ≥ 3，因为 n 防的是同一道题内部的重跑噪声。

**把覆盖做成第五道闸、不过就关整个比较节。** 否决。前四条是整个 run 的前提——题面、环境、受试对象、程序一致——任一不过，任何一对都不可比。覆盖是某一对格子的属性：一格的判官失败对其余配对毫无影响，而关整节还会连带藏掉判据表，那恰恰是读者看「哪条判据由哪一层判」的地方。只降级出问题的那一对，撤回的是没有根据的结论，留下的是所有有根据的事实。

**加「补判」按钮或新增判官缺席注解。** 按文案否决：失败已由 `runJudgeSamples` 记录，重判是流程决策，不属于报告。

## 后果

得到的：报告不再对两种不同判定来源之间的落差排名或给区间，也不再从一道题里印出零宽区间。每一对的原因逐条写明，附判官自己的报错原文。

代价：小而完整的实验会失去区间——2 题 × 3 次（S2 夹具）与 1 题 × 3 次（S9/S10）现在不给区间因而不排名，此前是能排名的。这是 D7 的本意，但对跑短 pilot 的人是看得见的行为变化。

## 测试

`packages/eval`：942 个测试全绿，`tsc -b --noEmit` 干净。新 describe「report — D7 verdict coverage and CI thresholds」：一侧有判官、另一侧只有脚本时降级这一对（不关整节）；人改一条判据不降级；1 题 × 1 次不给区间；3 题 × 1 次给参考区间、不排名；5 题 × 3 次仍然排名。S2/S5/S8/S9/S10 与 report-face 的校验 id 按新口径更新。
