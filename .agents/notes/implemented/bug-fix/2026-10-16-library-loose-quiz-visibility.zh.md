# Agent Note: 图书馆 —— 不挂站的测验也找得到了

Status: implemented

## Problem

`putQuiz` 一直接受不挂站的作用域（书级，或连书都没有的完全自由卷），但侧栏只在 quiz 站的「章节考」tab 下列测验。教练写一张书级测验——当路线上全是 practice 站（拒绝挂测验）时这是自然选择——落库后在面板里没有任何入口：学习者被告知「出题了」却到处找不到（2026-10-16 微积分实盘会话）。

## Decision

- **书籍页新增「本书测验」**——这本书不挂站的测验，每行点开即答卷。
- **项目页新增「自由测验」**——既不挂书也不挂站的测验。
- **站的关卡 tab 显示同作用域的不挂站测验**：quiz 站的「章节考」在本站测验之后列出；practice 站的「章节考」（验收单）在验收标准与提交钮之间列出所覆盖书的「本书测验」——「完成本站测验（book 级）」这样的验收行从此指得到一个看得见、点得开的目标。
- **`putQuiz` 对不挂站的测验回 warning 指明落点**（书籍页「本书测验」/ 项目页「自由测验」，并提示「传 node 才能挂站」），`quiz` / `node` 工具参数描述带上同样的指路，教练能告诉学习者去哪找。
- 共享行渲染是 `QuizRows`（client/views/book.tsx）；测验路由的 book 取自测验自己的 scope，绝不取自发起视图。

## Alternatives considered

- **拒收不挂站的测验**：否——自由练习卷是有意留的旁路；缺口在展示，不在存储。
- **把不挂站的测验隐式挂到书的当前站**：否——会把这次作答归错档，甚至静默完成一站；显式 scope + 可见列表才是诚实的。

## Consequences

- 存量不挂站测验无需迁移即可见。
- quiz 站的「章节考」改为读整本书的测验列表再在客户端拆分（一次更宽的 Remote 调用，代替按节点过滤的一次）。

## Testing

service.spec：不挂站的测验回 warning 指明落点（书籍页 / 项目页）；照片取证的测验断言现在钉住落点说明是它的唯一 warning。122/122 + `check:panels` 绿。
