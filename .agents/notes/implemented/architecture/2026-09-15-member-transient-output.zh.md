# Agent Note: 成员瞬时输出通过公开 Conversation 扩展呈现

Status: implemented

## Problem

外部镜像会话没有原生 Agent。宿主 assistant-stream 总线要求真实 Agent，而频繁写入完整前缀的 assistant 消息会放大持久日志，并把浏览器延迟与持久化耦合。原生子 DSH 的 wire 也只转发完成事件，没有生成帧。

## Decision

Core 持有瞬时注册表与流式 Remote。每个被查看的会话收到当前基线及有序后缀补丁，重写快照显式替换。慢消费者只保留上次送达状态；重连从当前基线开始。浏览器中同一成员共享订阅，最后一个实时节点卸载时关闭。

生产者在预留 step 写入仅日志的 `local-agent/stream` 锚点。公开 Conversation definition 使用官方 Markdown 组件呈现文本。相同坐标的原生最终 assistant 消息隐藏临时节点；引擎要求保持稳定节点并设为隐藏，不能撤回已经物化的节点。原生工具、最终内容、用量和导航继续使用原有路径。

恢复检查点独立按一秒节奏保存后缀字节，非前缀更新显式替换，使普通追加输出的恢复字节量随输出长度线性增长。生产者释放时保存剩余部分。三家外部 provider 在 core 提供该能力时使用新通道，旧 core 兼容仍走快照路径。子 DSH headless 进程经新增 wire 通知转发真实 Agent 的原生帧；父侧过滤轮次与 attempt 身份，使用公开 BlockAssembler 组装文本与 reasoning，并在取消时保存带 interrupted 的部分消息。

Claude 使用原生消息 ID 与内容块索引配对部分和完成事件，旧帧退化为按消息顺序分配的 key。Kimi 在新的 ACP 工具调用处划分生成段，在延迟 wire 折叠前预留工具坐标，并按序消费同类型片段。ACP 没有通用文本子项身份，所以这里使用已知边界退化，不伪造厂商 ID。

## Alternatives considered

**伪造原生 Agent 流总线。** 镜像 Session 不是 Agent，不符合宿主所有权合同，因此拒绝。

**每次显示批次都写完整持久消息。** 仅保留为旧 core 兼容路径；长回复产生平方级前缀字节，且无法独立控制持久化节奏。

**修改浏览器 Session 的事件源。** 公开 Session 面对历史只读；导出实现类不代表允许修改其他服务持有的状态，因此拒绝。

**替换整个转写视图。** 无需如此；公开事件 definition 与 keyed 聊天 renderer 可以保留时间序位置，同时保留原生最终渲染与导航。

## Consequences

无需修改宿主源码。连接丢失时保留最后显示的部分内容，并以新基线重连。宿主崩溃可能丢失尚未落检查点的末段；检查点节点明确保留为部分记录，不伪造已完成答案。检查点仅在日志中，不进入模型消息。卸载插件会隐藏未完成的自定义展示，但保留原生已完成转写。

50ms 发布调度与独立持久化路径只是实现基础，不是已经测量的浏览器 P95 结论。同 kind 的 provider 子项身份、完整原生内容覆盖、真实浏览器延迟与全新安装/升级验收仍由总协调者提案跟踪。DSH 生成中会合并呈现文本与 reasoning 块；最终原生消息保留原始块结构。

## Testing

测试覆盖基线/后缀/替换/移除、慢消费者、取消清理、重连不重复文本、检查点字节增长、最终化取消定时器及部分恢复。真实公开 Conversation assembler 验证实时及回放时的原生最终消息替换。Provider 测试覆盖完成前的瞬时输出、最终原生用量、DSH 轮次过滤和中止部分内容保留。
