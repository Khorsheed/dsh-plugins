# Agent Note: 将房间协调工具绑定到已认证成员

Status: implemented

## 问题

外部协调者可以接收房间输入，但成员桥接只有需要确认的消息工具，无法读取房间或邀请执行成员。Room gate 抛错还会回退到 family 直接执行，绕过房间裁决。

## 决策

成员桥接提供 room_read、room_invite 和 room_message。宿主根据注册 token 识别调用者，要求处于有效配置轮次；空闲、过期及准备阶段 token 不能调用房间命令。Room 将子会话和 provider 与花名册核对。工具参数不能指定发送者或父房间。只有当前协调者可以邀请及派发，成员可以读取有界房间上下文。

原生 DSH 和外部协调者通过同一 room 服务邀请成员及后台发消息。原生伴生工具通过能力探测增加 room_read，共用上下文读取逻辑。交接后旧原生协调者不能再邀请、派发或修改旧共享任务板。协调者发出的 member_message 也走 room 派发。执行成员的临时转告保留原确认 gate，持久执行的完成回报仍自动投递。

邀请携带 firstTask 时记录发起协调者作为回报目标，完成后沿用 room_message 的关联回报路径。MCP 调用返回接受结果，不等待执行。切换角色前检查 core 的工具通道是否正在监听。此传输检查不等于真实 CLI 已成功调用全部工具。

现代 room gate 显式报告所有权。一旦认领房间，操作拒绝或所有权读取失败均返回错误，绝不回退到 family 执行。不支持所有权探测的旧 gate 保留旧版 decline 合同，room 缺席时仍允许 family 内消息。

## 考虑过的替代方案

**让模型传房间和调用者 ID。** 身份将由调用者自报，可能指向其他房间。Token 提供两种身份，额外命令参数被拒绝。

**所有协调请求继续逐条人工确认。** 普通后台委派会在每条消息上暂停。协调者权限和持久投递提供所需异步路径，无关的执行成员转告保留已有 gate。

**任何 room 错误后直接发送。** 权限或持久化失败将绕过权威房间。显式所有权使这些失败成为最终结果。

## 影响

外部协调者可以读取房间、邀请执行成员并接收完成回报，无需 DSH 模型转发。两种工具传输共用角色校验和持久派发语义。不修改宿主源码。

正式 goal/task/attempt 工具合同、core 共用消息队列、更广的成员自动通知策略及真实 CLI/浏览器验收仍未完成。测试覆盖认证身份、无效/空闲/准备 token、注入房间参数、旧协调者拒绝、首项任务回报、桥接协议、可选原生工具注册及工具通道缺失时拒绝切换。
