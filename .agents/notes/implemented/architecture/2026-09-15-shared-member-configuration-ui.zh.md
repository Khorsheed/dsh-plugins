# Agent Note: 共享模型目录与成员配置界面

Status: implemented

## Problem

Provider 设置页与 room 邀请页只展示模型字符串列表。成员 composer 忙时禁用换模，而 room 编辑同时写 broker override 和 roster 模型，形成两个状态所有者，失败语义也不一致。

## Decision

Core 提供可选的客户端 harness 模型目录与成员配置渲染器。设置卡和 room 邀请使用同一目录字段：原生名称、完整 ID、来源提供时的解析别名、来源标记、描述、搜索、自定义 ID、刷新，以及不完整/过期/错误状态。选择器展开时订阅目录更新；更换 provider 时立即隐藏旧 provider 的候选。

成员会话与 room 编辑共用按成员引用计数的配置订阅。本轮准入配置与下轮已准备、待生效选择分开展示。忙时仍可选择；应用、撤销、重试与版本冲突均交由 core 控制器。冻结评测与断线状态明确禁用控制；迟到的读取响应不能覆盖较新的订阅阶段。成员 composer 保留独立发消息、Stop 和统计行为。

Room 通过服务探测取得渲染器，不在运行时导入 local-agent 包。服务缺席时保留兼容控件。已启动成员的模型状态只归 core：配置请求后不再重复写 room roster 模型。兼容入口仅改模型成功时直接关闭，不提交空的元数据修改。未启动成员仍在 roster 保留创建配置。

## Alternatives considered

**每个 provider 和 room 各复制一份菜单。** 不采用，因为目录来源与忙时语义已经发生分叉。

**把接受选择当作运行观测。** 不采用。面板标明已准备与本轮配置；原生模型确认仍不代表实际生成使用了该模型。

## Consequences

后续协调者路由可复用共享控件。原生 room main 控制、冻结评测调用、协调者生命周期及认证后的浏览器验收仍在进行中。本批不改变生产 profile 或凭据。

## Testing

Core 客户端测试覆盖两个入口同步进行中选择与撤销、旧草稿冲突、冻结条件、迟到读取竞争、异步目录与 provider 身份切换。Room 测试覆盖共享渲染及删除重复/空元数据写入。包构建和完整受影响测试作为提交门禁；真实浏览器延迟与认证运行时验收另行完成。
