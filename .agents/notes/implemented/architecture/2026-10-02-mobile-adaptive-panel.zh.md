# Agent Note: 保留状态的自适应文件面板

Status: implemented

## Problem

local-files 在手机宽度里仍将 300 像素文件树与预览并列，剩余预览宽度不足以阅读。逐插件复制移动版会增加维护成本，并可能在布局切换时丢失选择或草稿。

## Decision

源码面 content-preview 共享库导出 `AdaptiveSplit`。它观察自身容器，小于 560 像素时逐层显示保留挂载的页面，达到该宽度时并列显示。窄屏打开详情将焦点移到返回按钮；返回时尽可能恢复原操作控件。两侧持续挂载，子组件状态和滚动容器在导航、缩放布局时保留。隐藏标签页产生的零宽观测被忽略。没有 ResizeObserver 时使用初次测量的宽度；无法测量时保留两侧可访问。

local-files 将原有 FileTree 与 ContentPane 接入组件。选择文件进入详情，返回动作恢复文件树。会话或根目录变化时返回文件树。宽屏保留原有分隔条，主列表最大占 45%，为内容留出空间。不增加运行时插件依赖或宿主 API。

可运行预览直接导入真实共享组件，文件和内容使用模拟数据。安装依赖后，在仓库根运行 `node packages/ui-content-preview/examples/adaptive-split/serve.mjs`。它只监听本机回环地址的 8873 端口；`MOBILE_PREVIEW_PORT` 可覆盖端口。启动器复用工作区 Vitest 的 Vite 依赖。它不连接宿主实例、不修改 profile，也不代表完整插件集成验收。

## Deferred

此分支是共享布局的首批改动，不是完成了全部移动适配。剩余范围按归属列出：

| 归属 | 剩余工作 | 验收 |
| --- | --- | --- |
| mobile 导航 | 面板动作与新增会话并列；保留可发现的标题重命名；通过可选公共 sidebar 服务接入并提供降级 | 320 像素下两个动作可用；缺少能力不导致启动失败 |
| 官方 sidebar 外壳 | 移动端全宽面板页、紧凑标签切换、新增/关闭面板、返回聊天 | 保留标签选择和子页面导航；宿主修改走上游流程 |
| 共享文件类面板 | worktrees 等适用面接入保留状态的列表详情布局；内容工具条响应式、溢出处理和触控尺寸 | 文件、diff、表格、预览控件可读；不复制移动渲染器 |
| canvas | 保留卡板、连线、分区、草稿和成稿；整页详情、显式选择/连线模式、触控平移缩放 | 创建/删除连线、退出草稿编辑均保留原有状态；与进行中的画布工作协调 |
| 终端和嵌入内容 | 终端尺寸、键盘辅助操作和视口；嵌入内容全宽展示并维持现有沙箱边界 | 键盘和安全区不遮挡输入；内容安全约束保持 |
| 状态和真机验收 | 区分首次加载、旧缓存内容与真实断连；刷新时保留有用状态 | 用日志核实重连；在 iPhone/WebView 验证后台恢复、键盘、滚动和手势 |

画布示意使用模拟交互，不代表正式画布已完成触控改造。现有 canvas 实现未修改。浏览器预览无需安装 App 即可评审布局和交互；真机验收通过可访问的测试实例进行。仅网页变化通常更新实例即可，原生桥变化则需要重新构建 App。

## Alternatives considered

**每个插件单独实现移动渲染器。** 否决，因为会复制内容行为，使移动端和桌面端的功能一致性更难维护。

**全局 CSS 隐藏任意插件子元素。** 否决，因为外壳无法推断插件的选择、导航和草稿归属。共享布局需要一个明确且小的列表/详情契约。

**卸载非活跃页面。** 否决，因为筛选、展开的目录、焦点和未保存的局部状态会重置。保留挂载让原组件继续负责自身状态。

## Testing

共享组件测试覆盖宽窄切换、DOM 身份保留、草稿/筛选保留、焦点返回、零宽观测、观察器清理和缺少观察器时的降级。local-files 原有测试验证文件和 store 行为。浏览器检查使用独立预览，不宣称生产部署或手机验收已完成。

## Consequences

单一源码实现负责布局切换，并内联进每个消费插件。隐藏页面继续运行原有副作用，避免重挂载，但不会降低内存占用。接入需要显式声明；画布和终端的专门手势仍由各模块处理。预览启动器依赖 Vitest 继续提供 Vite 依赖。
