# Agent Note: 保留状态的自适应面板

Status: implemented

## Problem

桌面 sidebar 在手机上仍把文件预览挤在 300 像素文件树旁，桌面标签栏、分栏和浮窗也争抢宽度。为每个插件复制移动端渲染器会增加维护成本，并让画布连线、分区和草稿难以保持功能一致。

## Decision

源码层 content-preview 库导出 `AdaptiveSplit`，观察自身容器：小于 560 像素显示一个保留挂载的界面，更宽时显示两栏。进入详情聚焦返回按钮，返回时尽可能恢复原控件焦点。两侧保持挂载，保留子组件状态与滚动容器；忽略隐藏标签产生的零宽度观察。没有 ResizeObserver 时使用初始可测宽度；不可测则保留双栏。

local-files 和 worktrees 用原有树与 ContentPane 接入。选择条目打开详情，返回不清空选择或已获取内容；会话、根目录、模式或工作树变化分别重置详情导航。宽屏保留分隔条，主栏最多占 45%。ContentPane 通过容器查询换行工具栏；窄屏标题操作组采用 32×40 像素点击区域，去掉按钮间额外间隔，为文件名留出空间，文件目录工具栏也去掉图标额外间距。宽容器间距不变。这些都是源码导入，不增加运行时插件依赖。

mobile 在新建会话旁增加面板入口。可选的结构化 `sidebarRight` 能力探测负责当前会话清单、聚焦、展开、关闭和打开引导页。公开数据源未报告布局变化时，以经过检查的 sidebar/dock 锚点通知展示更新。全宽移动面板用返回、可横向滚动的具名多标签和添加替代桌面标签栏，关闭按钮归入活动页签。独立的 52 像素面板导航让活动页签与内容区衔接，连接提示单独占位，不再撑高标签；仅展示活动栏（包括浮窗），不改写宿主保存的分栏和浮窗位置。内容留在原宿主中，保留策略仍由宿主负责。缺失能力或锚点时保留原生入口；操作失败保留选择并显示可重试错误。打开替代面板时聊天内容 inert，返回恢复入口焦点。受管理面板及声明手势归属的内容不会触发全局导航侧滑。

移动端全屏与宿主是否保留右侧栏宽度无关。受管理面板打开时，将右列以自动 grid 定位锚定到整个 frame，包括宿主标记右列已收起、宽度为零的情况，面板百分比宽度才能按整个 frame 计算。只有 mobile 入口存在时才隐藏原生 `data-sidebar-right-expand` 按钮，入口撤回时恢复宿主按钮。新建会话页的隐藏新建动作不再占位，唯一面板入口贴齐右侧。

重复选择保持幂等：再次选择同一文件、diff 视图或提交时，不能在加载 effect 的键没有变化时清空已获取数据；预选的第一条提交也遵守此规则。文件读取中明确显示加载状态，提交读取中或失败时不伪装为零文件详情。共享返回控件采用独立箭头和 10 像素间距，点击区域至少 48 像素。

触屏和触控笔长按归原生文字选择，mobile 不再用同一手势打开竞争的消息弹窗，原有消息动作栏仍可用。指针右键菜单在出现文字选择时关闭。quote 忽略界面控件中的文字选择，并在粗指针设备使用底部动作栏，原生选择菜单留在文字附近。真实 iOS 菜单交互仍需设备验收。Reader 翻译能力未修改：它依赖浏览器 Translator API，没有服务端后备，移动端缺失该能力时会隐藏翻译动作。

画布保留原有卡板、连线、分区、绘图和成稿模型。LinkView 增加紧凑模式下的平移、选择、移动、连线操作，两次点选连线，关系列表选择删除，以及 50–200% 缩放按钮。世界坐标不受缩放影响，一次完成的移动仍只写一次。指针取消、第二个指针、失焦和卸载会取消待提交操作。每块画布记忆缩放比例，与选择和滚动状态同属视图记忆。紧凑控件显示此前仅悬停可见的动作。标签工具栏换行，详情分栏在窄容器中上下排列源码和预览。未实现双指缩放，缩放由按钮提供。无需改画布 schema、Remote 契约或宿主源码。

## Preview and acceptance boundary

原共享布局样例用 `node packages/ui-content-preview/examples/adaptive-split/serve.mjs` 启动，监听回环端口 8873。综合样例在 `packages/mobile` 下执行 `pnpm exec tsx examples/panels/serve.ts`，监听回环端口 8875。它导入真实 MobilePanelNavigation、宿主 DockLayout、AdaptiveSplit 和 LinkView，数据为内存样例。样例导入宿主真实 AppFrame 和 SidebarRight 样式，包含保留会话包装层和面板 body，默认使用已收起的零宽右列且只打开引导页；右侧栏宽度开关覆盖两种几何状态，新建会话开关覆盖入口位置；深浅色开关与完整文件操作组覆盖导航对比度和图标间距。文件浏览器和工作树使用真实插件组件与状态仓库，注入延迟返回的 Remote 样例数据；只有卡片编辑器仍为样例控件，不读取生产文件或提交。源码解析器与测试共享。mobile 包只发布原有 ingress `.mjs` 示例，仓库内预览不进入发布包。

终端内容受益于全宽宿主容器及已有视口处理，全局侧滑排除 xterm。未添加终端快捷键栏：它需要官方输入能力，不能模拟 DOM 按键。嵌入内容保持原沙箱边界。真实 iPhone/WebView 的键盘、安全区、前后台恢复和终端验收仍待完成；组件样例不是部署实例或手机测试。

用户反馈的首次加载信息暂时消失尚未结合连接日志复现。本次变更不声称修复其原因，也不更改重连策略；实例验收需区分首次加载与传输故障。适配不需要重建原生 App；生产验收通过仓库部署流程进行。

## Alternatives considered

**每个插件单独复制移动渲染器。** 拒绝：重复内容行为，增加功能一致性维护成本。

**用全局 CSS 隐藏任意插件子元素。** 拒绝：外壳无法推断插件选择、导航或草稿归属。外壳 CSS 仅处理已检查的宿主容器，主从布局需要明确的共享契约。

**卸载或搬移非活动内容。** 拒绝：草稿、过滤条件、滚动、iframe 和终端状态可能重置。共享面板保留挂载，外壳适配保留宿主内容树。

**为手机改写持久化停靠状态。** 拒绝：切回桌面会丢失分栏和浮窗位置，移动展示不改写这两者。

**修改上游宿主或模拟终端输入。** 拒绝：宿主源码只读跟踪，终端输入属于其原所有者；缺失能力走上游变更流程。

## Testing

共享布局测试覆盖 DOM 身份、草稿和过滤保留、焦点返回、宽度切换、零宽观察、清理和回退。local-files 与 worktrees 集成测试覆盖详情导航、重复选择、延迟读取，以及预选的八文件提交从保留列表再次打开。mobile 测试覆盖可见标签清单、键盘导航与触屏选区归属；quote 测试排除界面控件文字选择。mobile 测试覆盖所有者操作、能力或锚点缺失、失败、监听清理及手势归属。画布测试覆盖原桌面手势以及两次点选增删连线、平移不写入、缩放后的移动、取消和只读行为。回归样例复现了右列收起时修复前内容零宽、修复后内容全宽的差异。计算样式测试覆盖零宽右列的打开和返回、原生入口回退以及新建页动作占位。浏览器通过综合样例检查真实 DockLayout 展示与组件交互，手机及生产验收另行进行。

## Consequences

主从切换由一份共享实现负责并内联到使用方，专用画布手势仍归画布维护。保留挂载的内容继续持有效果和内存。mobile 外壳以经过检查的宿主 DOM 锚点作为通知回退接缝；未来锚点变化时必须撤回替代界面，保留原生访问。预览工具依赖工作区 Vitest/Vite 源码解析器和只读 harness 检出。
