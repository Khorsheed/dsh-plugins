# Agent Note：引用写明内容出处

Status: implemented

## 问题

在灵感空间文章里选一段引用，标签是「引用「<会话标题>」」：引用菜单给所有选区都贴当前会话的显示标题，所以引用文章时写的是旁边那个会话，而不是文章本身。另外，阅读器的翻译按钮只翻正文，标题（正文大标题和顶部栏）仍是原文。

## 决定

- **可选的 `data-quote-source` 属性。** quote 的 `classifySelection` 读选区所在范围最近的 `[data-quote-source]`，放进 `SelectionSnapshot.source`；菜单标签取 `source ?? 会话标题 ?? 兜底文案`，所有路线（标签、侧边对话、外部贡献的动作）一致。它只是 DOM 数据，不构成包依赖：不设这个属性的界面、或没装 quote 插件的宿主，行为不变。导出常量 `QUOTE_SOURCE_ATTR`。
- **阅读器在详情根节点上设这个属性**，值为读者看到的标题——显示译文时就是译后的标题。
- **标题跟着正文的翻译走。** 译文视图下大标题和顶部栏显示译文；对照视图下大标题下方再放原文；原文视图显示原文。标题和正文同一轮：页面内存 → 宿主的句子记忆 → 同一个翻译会话。模型新学到的标题并入正文那唯一一次持久化批次；存档译文路径（没有 Translator API）只读记忆。

## 考虑过的其他方案

**阅读器自己贡献一个带标签的引用动作。** 否决：内置的「引用到当前会话」那一行照样标错；标签属于选区，不属于某一行。

## 影响

- 这次改动之前保存的文章译文记录里没有标题：重新打开这类文章，会为标题单独调一次模型。
- 其他内容面板（文档预览、画布卡片）设同一个属性，就能让引用写明出处。
