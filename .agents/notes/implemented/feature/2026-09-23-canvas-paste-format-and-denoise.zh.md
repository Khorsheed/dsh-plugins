# Agent Note: canvas 0.4.7 — 粘贴的富文本保住格式，连线视图不再自我解说

Status: implemented

## Problem

用户走了一轮画布，提出四条抱怨，每条都有截图：

1. **把渲染态的聊天答复或网页段落贴进卡里，格式全丢了**——粘贴臂只转换表格，其余带 `text/html` 的复制落成光秃秃的文字（用户的原话是「复制 md 进来似乎会被直接清除为文本格式」）。而卡里恰恰表达不了的那个例外，正是这个表面存在的理由：留住另一个表面的 markdown。
2. **连线视图对每个手势都要解说一遍。** 舞台底下一行常驻操作说明、底栏的空选择引导、每个手势各配一条 toast——截图里拖着卡进分区就弹出「这张进到了『测试』」，而拖的结果明明已经在画面上。十条 toast 盖着结果本来就看得见的手势。
3. **图标跟宿主漂移。** 追问挂着裸 `→` 字符，两个「加」按钮拿全角 ＋ 当图标，橡皮干脆没有图标，标签条的 × 是 fill 变体在小尺寸下糊成一团。
4. **字体也在漂**：七个手挑字号（10.5/11/11.5/12/12.5/13/14.5），而宿主有现成的阶梯 token；还有一处引用了从不存在的 `--dsw-font-mono`（真 token 是 `--ds-font-family-code`，经 `--dsw-font-markdown-code-block-small` 到达）。

## Decision

**第六条粘贴臂：`formatted`。** `htmlToMarkdown`（`src/client/paste-table.ts`，纯函数，DOMParser）转换富文本复制的标记 flavor——标题、强调、删除线、行内代码、链接（只收 http/https/mailto）、多级列表、引用、围栏代码块、分隔线、表格；script 和 style 不过夜。两道闸守住这个模块的开篇规矩（「弄坏普通散文比不转换更糟」）：

- **诚实闸**：转换结果自己的纯文字与剪贴板的 `text/plain` 去空白逐字一致才落 markdown。丢了纯文本 flavor 里有的字的转换一律拒绝——丢内容正是这个模块要避免的失败。
- **无操作闸**：转换与纯文本逐字节相同（纯段落）时交回浏览器原生粘贴，不出声。

臂的边界随之挪动：表格臂只在表格是剪贴板的全部内容时启动（电子表格的 TSV 双份，或孤 `<table>`），夹在正文中间的表格跟着正文一起转，不再吃掉前后文；page 臂收窄到整文档（doctype/`html`/`head`/`body` 起手），聊天答复贴进空卡由此落成 markdown 而不是沙箱 HTML 卡；过不了诚实闸的片段仍兜底走 page 臂（iframe 渲染）——总比丢字强。`words` 只剩一种情况：整页文档贴进已有正文的卡。

**连线视图的规矩改成：舞台上已经看得见的结果，不再弹一遍。** 常驻说明行删了（可发现性一直由 hover 圆点和它的 tooltip 承担）；连线、框选、进/出分区、分区拖动、新建分区、扩圈开关、清空的 toast 全撤；底栏空选择时报板面自己的总量（活数据，不是提示），有选择时只说发送集、不再追加总量；取消选择在无可清时自己隐藏。只留下一条 toast：删掉这条线——从底栏按钮删一条 1.6px 的线，值得确认一句卡还在。被它降噪的表面见[连线视图笔记](2026-09-23-canvas-link-view.zh.md)。

**图标与字体并入宿主。** 追问的 `→` 换成宿主的 `IconRightUpOutline14`（与附件链接同款的开往别处），两处评论区经新的 `follow-up.tsx` 共享同一颗按钮；两个全角 ＋ 按钮换成 `IconPlusOutline16` 加纯文字标签（加一个 / 新分区）；橡皮和撤一笔画了包内自绘 glyph（`icons.tsx`，message-tools 的补 glyph 惯例——16 viewBox、`currentColor`）；标签条的 × 留在宿主的 `IconCloseFill14`（宿主自己的 TabPanel 用的就是它），尺寸提到可辨的 12px；铅笔/橡皮光标补了深色主题变体（原来白填充在深色底上直接消失）。全部 80 条字体声明搬进 `--dsw-font-*` 阶梯（10.5/11→xxxs-11，11.5/12→xxs-12，12.5/13→xs-13，14.5→s-strong-14；500 重的走 `*-strong-*` 变体；刻意的本地行高保留）。幻影 `--dsw-font-mono` 改读 `--dsw-font-markdown-code-block-small`。

## Alternatives considered

**Turndown（或任何通用 html→markdown 库）。** 拒绝：通用转换器回答的是「任意病理网页的 HTML 意味着什么」，那是一堆我们还得驯服的启发式；我们的转换器只回答剪贴板片段，而诚实闸让错误答案自己拒绝自己。零依赖，且保守的缺省活在比对里，不在转换器的聪明里。

**把逐手势 toast 当教学文案留下。** 连线是卡板的另一张脸，一张要先读说明才敢碰的脸已经失败了；圆点 hover 即现并自述其用，线看得见，底栏报告着手势说不出的那一件事（要发出去的是哪几张）。教学文案写于这个表面还什么都展示不了的时候。

**圆角和间距逐像素对齐宿主。** 作为超纲拒绝：宿主自己也硬编码圆角（没有 `--dsw-radius`），所以这次对齐的是有 token 的两样——字与色。几何保持本地。

## Consequences

- formatted 臂的代价是每次富文本粘贴多一次 DOMParser（在粘贴频率下不可测）和转换器的维护；换来的是这个表面的开篇承诺（卡片收得下你复制的东西）覆盖到最常见的那种复制。
- 诚实闸意味着一些正当转换会被拒绝（纯文本 flavor 与标记对不上的剪贴板——罕见，且总是退回文字）。这是选定的失败方向。
- 九个 locale key 和那行说明离开了字典；`paste.formatted` 进来。连线 spec 的 toast 断言换成了视觉断言（线出现、徽章翻转、按钮退役）——同一个表面的更好的一份规格。
- 全部由 0.4.7 承载。连线视图笔记的测试清单就框选一行就地更新；它记录的其余行为一律未动。
