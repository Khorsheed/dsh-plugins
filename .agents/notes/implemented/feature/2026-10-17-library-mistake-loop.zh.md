# Agent Note: 图书馆 —— 错题闭环（错题本、重考方向、作废题换题）

Status: implemented

## 问题

3080 实盘体验暴露三个缺口，都在错题驱动这条环上：错题在站页以外没有家（没有跨站聚合）；「这题有问题」只是把题作废不计分，教练永远不知道题坏了；考过的站再进去还是同一张卷子——没有新题，也没法把新题引向薄弱点。

## 决定

纯客户端，不动存储（错题与作废本就在 attempts 的账里）：

- **项目页「错题本」区块**（`MistakesSection`）：项目全部卷子的最近一场里答错的题（按卷+题去重，最新在前），带答案与来源，一键「围绕错题出一套」把清单带给教练（自由卷）。站级的「这一站的错题」保留——两处各管路过与坐下。
- **考过的站，主行动变成再出新题**：出题按钮从「请教练出题」变「再出一套新题」；出题方向 chips 在有错题时多一个「错题重考」（带错题数）——直接带重考话术（同薄弱点、新角度、不照抄原题）。
- **作废题闭环**：章节考 tab 列出作废的题（「你觉得有问题的题」）+「请教练换题」手势（prime.quiz.replace），教练提示词也教了：void 就是坏题——判分提到作废时主动提出换题。

## 已否决方案

- **单独的错题本 tab/路由**：否决——项目页就是学员的落点，那里一个区块胜过新去处；卡片页（来源 quiz）已覆盖弱点账本的读法。
- **作废自动触发换题**：否决——教练得先看到判分上下文（哪错了、为什么）；手势带的正是这个上下文。
- **线上新 focus 值 `missed`**：否决——重考话术是 prime 层的事，不是卷面 scope 的事；LibraryQuizFocus 保持 mine/book/mixed。

## 后果

- QuizTab 的方向状态是 `LibraryQuizFocus | 'missed'`——多出的 chip 只管 prime，不进 putQuiz。
- 项目页每次挂载多读一次 attempts + assessments（两个列表都小，且面板的轮询已缓存）。
