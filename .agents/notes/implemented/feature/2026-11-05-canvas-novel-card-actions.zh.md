# Agent Note: 小说卡片操作共用一个菜单，人物记忆以手动记录追加修正

Status: implemented

## Problem

小说各页面的删除按钮位置不一，人物外层卡看不出可以打开详情，可编辑记忆的控制方式也不一致。通用画布归档卡井仍直接摆放恢复和删除按钮，typed 字段与小说记忆编辑器没有统一的键盘行为，只读测试也只覆盖 proposed 卡，不能证明真正无会话的可保留卡只读。“当前打算”和“相信的事”是对账日志，若把它们变成普通卡字段，会丢失来源，并让下一次对账抹掉用户修正。

## Decision

- 世界观、人物、关系和伏笔头部统一使用 `NodeActions`：固定 ⋯ 菜单，查看详情在前，原有删除预览在后。人物卡另有明确的“查看详情”入口和悬停反馈。通用画布归档卡井也用同一个 `MoreMenu` 放置恢复和删除，不再直接展示按钮。
- “此刻”保留整体状态编辑器。“当前打算”和每条相信的事使用一致的手动修正入口与编辑器。手动修正会进入后续写作参考、不会因重新对账被删除的说明继续保留。
- typed `FieldForm` 和两类小说记忆编辑器在任意字段中都支持 ⌘⏎/Ctrl+Enter 保存、Escape 取消，并在保存/取消按钮旁显示提示。Markdown 块编辑提示补上 Escape；HTML 与 Markdown 源码编辑继续沿用 `CardTextarea` 的既有行为。
- 只读会话显示只读标记，保留阅读操作并隐藏写操作。通用详情页测试使用 `sessionId=undefined` 的可保留卡，检查菜单、typed 字段、正文编辑和评论，不再只依赖 proposed 卡。
- 修正向 `minds.jsonl` 追加一条 `origin=manual` 的记录，带当前章节；相信的事还保留亲历、听说或推测的来源。不伪造证据，也不替换自动提取记录。
- 对账只替换该章的非手动记录。手动修正始终通过写作参考的章节截止检查，保存后立即可见；自动记录仍沿用原截止规则。最新打算和近期相信的事因此包含人工修正，同时不丢失提取历史。
- `correctMind` 通过类型化 Remote 提供，与其他面板写操作共用会话围栏。

## Alternatives considered

- **原地编辑相信和打算。** 否决：会丢失自动提取的原文及章节证据。追加修正能同时保留两种记录。
- **手动记录也按章节截止。** 否决：当前章刚做的修正会从紧随其后的写作参考中消失。manual 只豁免这条截止规则，不豁免其他校验。
- **归档卡井继续直接显示操作。** 否决：这恰好保留了统一卡片头部已经消除的破坏性操作位置漂移。
- **只改快捷键提示文案。** 否决：旧 textarea 和记忆编辑器仍没有提示所宣称的行为。现在由表单级处理器统一实现保存与取消。

## Consequences

- 用户能看清哪些卡可以打开、哪些字段可以修改，以及修正会起什么作用。恢复和删除在普通卡与归档卡中都进入固定菜单，快捷键提示与实际行为一致。只读和可写会话在视觉上明确区分。
- 重新对账不会静默删除手动修正。新的自动记忆仍会替换该章此前的自动记录。
- 测试覆盖写作参考中的手动修正、重复对账、类型化 UI 写入、⌘⏎ 保存和 Escape 取消、归档卡井菜单、固定卡片菜单，以及真正无会话的可保留卡。
