# Agent Note: Datasets tab list and detail at the v5 hierarchy

Status: implemented

## 问题

T79 走查（场景 11、P1-11、P1-12、P2-15）把真机上的题集 tab 和交互稿 v5 并排对照，发现三处差距。列表没有表头。可见层原样写成「agent 可见：visible」。「用于」把 21 个实验名平铺成三行。详情页是文件树加一个空的右栏，可见性只靠逐文件的彩色标签说明。400 宽下右栏被挤成一字一行的窄列，顶部按钮的文字竖着折行。读者的两个问题——agent 从这个题集拿到什么、选手和判官各看到什么——都得靠解读名字来回答。

## 决定

列表页是一张表、一行表头：仓库 · 题集 / 最新版本 / 题数 / agent 可见 / 用在哪些实验。每个登记一条组行，其下一行一个题集。「用在哪些实验」一列（连表头）只在 eval 插件应答时渲染。

- **「agent 可见」写人话，不写层名。** `src/client/vocab.ts` 的 `layersPhrase` 映射已知层名：`visible` 是题面，`verify` / `grading` 带答案。
  - 全是已知层且都不带答案，写「只看题面」。
  - 有一层带答案，写「含答案」，未知层名跟在后面。
  - 没有答案层又有未知层名时无法判定，就原样写层名。
  - 悬停 title 总是列出确切的层名。遇到未知层名时再加一句：它不在词表里，页面不猜。
  - 详情页顶栏用同一个组件（`parts.tsx` 的 `LayersWordView`）。
- **「用在哪些实验」只写计数。** 写成「N 个实验 · 分布在 M 个版本」，点一下展开实验名和各自钉的 commit。
  - 按 `experimentId` 合并 run（重跑不算另一个实验）。
  - 版本 = 不同的钉住 commit。
  - 按题集 id 匹配；快照带登记 id 时再按登记 id 过滤，两个登记各自的 `default` 题集不会共用计数。
  - 为此，结构镜像（`client/index.ts`）与 `DatasetExperimentRow` 新增 `experimentId`、`registry`、`commit` 三个字段。它们在镜像上是可选的，老版本 eval 退化为「只按题集匹配、计为未钉版本」。
- **「题数」来自每个登记一次不带题集的 `list`。** `registry` RPC 本身不带计数，本任务又只改 client。
  - 加载中或读取失败时这一格是破折号，从不写 0。
- **详情页：打开一道题后两栏并排**——「选手将看到」（沿用 brief 里的选手文件）与「只有判官和探针看得到」。
  - 后者列出这道题及题集级在非 modelFacing 层里的文件。它是用树上标签所依据的同一份层声明算出来的补集。
  - 栏底一行是「可判性」。
  - 树上逐文件的标签保留，作为次要信息。
- **窄屏布局**看视图自身的宽度（`container: datasets-view`），不看窗口宽度。
  - 窄于 700px 时，右栏整块移到树下方，整页一起滚动。
  - 右栏窄于 520px 时，两栏上下排。
  - 顶栏按钮只整枚换行（`flex: none; white-space: nowrap`），标题那一半先截断。

## 考虑过的替代方案

**在宿主的 `registry` 应答里加题数。** 这样仍然只有一个 RPC，但任务限定只改 client 与 README。每个登记一次 `list` 也不贵：它只读 git 对象，而且是一个仓库一次，不是一个题集一次。登记多起来时，把计数挪到宿主侧是自然的下一步。

**照 v5 画成「只看题面 | 含答案」分段开关。** v5 把它画成可改的设置。改一个题集的层是登记 / 编辑表单的事（人的动作，前面有确认）。列表页上再放一个写入口会绕过那张表单，所以这里只读显示。

**按启发式归类未知层名（比如 `answers*` 算带答案）。** 任务写明不猜。错写一个「只看题面」正是这一格绝不能犯的错，所以未知层名原样显示。

**用两栏取代文件树。** 文件预览与槽位筛选都挂在树上，作者也是靠树找到放错的文件。两栏让人一眼完成自查，树留着干活。

## 后果

- 列表页不再只有一个 RPC，而是 N+1 次调用（registry，加上每个带题集的登记一次 `list`）。client 测试钉住了不带题集的那次调用，以及「破折号、从不写 0」的回退。
- 判官栏只列路径，没有字节数（`ItemRecord` 只带路径）。选手栏的字节数仍来自 brief。
- 层名词表重复了协议里的层名知识（`grading` / `verify`，也就是 `validate` 可判性检查认的那两个名字）。用别的名字存答案的仓库会显示原样的层名，不会被错写成「只看题面」。
- `tests/vocab.spec.ts` 钉住四种写法。`tests/DatasetsView.client.spec.tsx` 钉住表头、计数的展开（按实验与登记过滤、版本计数）、破折号回退，以及判官栏的补集。
