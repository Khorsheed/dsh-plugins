# Agent Note: 画布标签条只放画布，卡片靠面包屑回来（方案 B）

Status: implemented

## Problem

[画布内部标签条](2026-09-23-canvas-inner-tab-strip.zh.md)让一排标签同时装三样东西：画布的板、一张卡、一份没存的草稿。用了几轮，问题都出在这种混装上：

- 点几张卡，标签条就被卡片行挤满，画布反倒不好找了。
- 卡片行的标签写的是分类（「灵感」「问题」），看不出是哪一张。
- 回卡板要在标签条里找回那块画布的行，而且回来以后筛选、勾选、滚动位置都没了（切画布时一律重置）。
- 返回按钮是临时画的，和宿主的工具栏不是一路风格。

2026-09-27 评审时，用户在几个方案里选了 B：标签条只放画布，卡片在画布里就地展开，靠面包屑回来。用户还要求「尽量复用宿主原本的素材和风格，但做的更有设计感一些」。

## Decision

**一块画布一行，行记着站在哪。** `space/selection.ts` 的行改成 `{ id: b:<canvas>, canvasId, at }`，`at` 三选一：卡板 / 某张卡（带 heading）/ 草稿（带分类）。

- `openCardTab` / `openDraftTab` 只改那一行的 `at`。
- 新增 `backToBoard`。
- `openCanvas` 保留原来的 `at`，所以切走再切回来，还站在原来那张卡上。
- 一块画布一行，所以一块画布只有一份草稿，这条是结构保证的，不靠查找。
- `forget(canvas, card)` 只在那一行正站在被删的卡上时才退回卡板。
- 满 16 行时挤掉最早的那块画布，站在草稿上的行最后才挤。
- stash 形状变了。0.4.6/0.4.7 存下的卡行、草稿行，读回时折成一块画布一行、站在卡板上。草稿的字从来不进 stash，折回去不会丢东西。

**面包屑（`detail/DetailCrumbs.tsx`）。** 顺序是：‹ 回卡板 · 画布名 / 卡名 · ‹n/m› · ⋯。

- 卡名取正文第一行（`cardTitleOf`），不再显示分类。
- 画布名比卡名淡一档：卡是你在的地方，画布是你要回去的地方。
- 画布名本身也能点回去。
- ‹n/m› 走的是卡板**当前筛选下显示的顺序**（`shownCardsOf`）。卡板没显示的卡（被筛掉或已归档）不出步进器，只有一张卡时也不出。
- 按钮沿用宿主侧栏浏览器 `.tool` 的做法：28px、无边框、平时淡、悬停填底。图标用宿主的 ChevronLeft/Right（经 `sync-icon-artwork` 同步进来），提示用宿主的 `Tooltip`。

**分类挪到元信息行。** 分类显示为一枚宿主 `Tag`，点开是宿主 `Menu`，列出本画布启用的分类，当前那项打勾。选一项就地改分类：已有的卡走 `patchCard {kind}`，草稿走 `openCardDraft` 换分类。

**每块画布的视图记忆。** `CanvasTab` 按画布 id 把筛选、勾选、卡板/连线视图、「显示已归档」和连线视图里选中的线存进一个 map。选中的线原本是 `LinkView` 的内部状态，这次提到上层，由 `wire`/`onWire` 传进去。滚动容器打 `data-canvas-scroll` 标记，`onScrollCapture` 按「画布:容器」记下偏移，回到卡板时在 layout effect 里恢复。这些都只在内存里，不进 `sessionStorage`。

**离开草稿都要先问。** 标签条的 ×（「关闭这块画布」）、面包屑的 ‹ 和 Esc 走同一个 `leaveRow`：草稿有字或有笔画就弹同一个确认框，确认后再关行或回卡板。草稿保存后回到卡板。

**入口改成「画布 ▾」**，「＋ 新画布」挪到下拉菜单顶上。按用户的要求，不加快捷键。

## Alternatives considered

**方案 A：保留卡片行，只把标签文字改成卡名。** 标签条被挤满、回不去卡板这两个根本问题都还在。

**方案 C：卡片开在宿主 dock 里。** 0.4.5 走过这条路，0.4.6 撤回了：宿主关 tab 时不给拦截，草稿会被静默丢掉。

**把视图记忆写进 `sessionStorage`。** 这些都是一次会话里的临时状态，刷新后从头开始也可以接受；写进去反而要为筛选的分类 id、线的端点多做一层形状校验。

**卡名用分类名加序号。** 用户明确指出应该显示卡片名，不是卡片类型。

## Consequences

- 标签条不再能同时并排打开同一块画布的两张卡。要对照两张卡，只能用 ‹n/m› 来回翻，或者用连线视图。
- 草稿一刷新就回到卡板，和以前一样，现在 stash 的读法把这一点写明了。
- 视图记忆随页面关闭消失。
- dock 芯片的标题读 `at.heading`：站在卡板上显示「画布」，站在卡上显示「画布 · 卡名」。
