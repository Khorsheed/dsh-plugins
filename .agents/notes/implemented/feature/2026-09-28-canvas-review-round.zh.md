# Agent Note: 画布 2026-09-28 评审轮：卡片头部、编辑器工具栏、新卡虚线格、标签条、笔触粗细

Status: implemented

## Problem

用户在 3080 上走查画布 0.4.8，提了六点：

- **卡片头部。** 「与 Agent 对谈」「开始写作」不自然。对谈用引用整卡就能完成；开始写作看不懂是什么意思。
- **编辑器工具。** 手绘/图片工具位置太靠下，容易看不到。图片不能拖进来，也不能放大预览；保存按钮和纸面是分开的。用户希望它更像一个整体的编辑器，以后表格之类也能放进来。
- **新卡。** 新卡会跳到单独一页，显得突兀。用户建议在现有卡片后面放一个虚线格。
- **顺线扩一圈。** 这个连线视图里的操作看不懂。
- **标签条。** 画布内标签条叠在侧栏标签下方，不好看；× 太小，也不是官方图标；太阳图标也奇怪。
- **笔触粗细。** 模型之前说过手绘能支持多种笔触宽度，用户问现在能否支持。

## Decision

**卡片头部。** 对谈和开始写作移出卡片头部。引用整卡放进 ⋯ 菜单；卡片转成稿的操作改名为「让 Agent 写成稿」。

**编辑器。** `BlockEditor` 是一整张带边框的纸面，顶部是吸顶工具栏：

- 左边是插入组（`role="toolbar"`，插入），由 `InsertTool[]` 列表生成。现在有手绘和图片，以后加表格只是多一项。
- 右边是 ⌘⏎ 提示和 取消/保存。
- **拖入。** 拖入图片时插在离指针最近的缝隙。`gapAt(clientY)` 按各块 `data-slot` 的中线找到这个缝隙，拖动时用「放到这里」横线标出。拖入的不是图片时，提示「只能拖入图片」。
- **预览。** 点图片打开宿主的 `ImageLightbox`，编辑态和阅读态都可以（`useImageLightbox`，点击委托在容器上）。链接里的图片仍按链接处理。

**新卡。** 新卡从卡板网格末尾的虚线 ＋ 格开始（`DraftTile`）。卡板为空时，它是第一格，并带上空卡板的引导文字。

- 虚线格就地变成草稿：选分类、写文字、取消/添加，⏎ 直接建卡。
- 「展开」把已写的文字带进完整编辑器，用来加手绘或图片。
- 顶栏的分类菜单改为用该分类打开虚线格草稿，不再跳页。

**顺线扩一圈**已删除。

**标签条。** 改为下划线标签，用官方的关闭图标，去掉太阳图标。按用户要求，仍然可以同时打开多个画布。

**笔触粗细。**

- 细/中/粗 是画笔旁边的分段控件，只在拿起画笔时出现。上次选的粗细会带到下一个画板（模块级记忆）。
- `CanvasStroke.size?: 'thin' | 'medium' | 'bold'` 只在不是「中」时存储。`normalizeDraw` 和 `appendStroke` 会丢掉 medium 和未知值，所以所有旧笔画都读作「中」。
- `strokePathOf` 把 perfect-freehand 的 `size` 按 0.5 / 1 / 1.9 缩放；正在画的笔画也按所选粗细预览。

**同日第二轮（0.4.10）。** 在 3080 上看过之后：

- **编辑器铺满页面。** 纸面占满页面剩余高度（`flex: 1 0 auto`，最低 320px）。文字放在居中、约 760px 宽的阅读栏里（`padding-inline: max(18px, (100% - 760px) / 2)`），字号 14px、行高 1.8。最后一个文字块延伸到纸面底部，点下半部分的空白也会落进它。
- **虚线格草稿撑满格子**（最低 180px，文字区占满头部和底部之间的空间）。
- **删掉顶栏的「＋新卡」菜单。** 它和虚线格重复，也显得突兀。分类在虚线格自带的下拉里选。
- **虚线格文案改为「新增{分类}卡片」**，按它要新建的分类命名，例如「新增灵感卡片」。

**同日第三轮（0.4.11）：Markdown 里的整块 HTML。** Agent 在成稿里画了一个 `<div style=…>` 图示，页面上显示的却是源码。原因是宿主的 `MarkdownText` 有意把原始 HTML 当文字显示，也没有扩展口。

- `splitHtmlBlocks`（`src/html-blocks.ts`）在渲染前切出整块。切块条件是行首（最多三个空格）为块级标签，且这个标签在后文闭合；嵌套、跨行、跨空行都按同名标签的深度配平。
- 行内 HTML、代码围栏里的标签、没闭合的标签都保持 Markdown，不会吞掉后文。没有块的文本原样返回，仍由一个 `MarkdownText` 渲染。
- 每个块用和 HTML 卡片相同的沙箱渲染（`CardMarkdown`，复用 inline-html-render 的 `buildCardSrcDoc` + `attachBridge`）：严格的卡片 CSP、不联网、脚本关在不透明源里，高度由桥接回报。卡片详情的文字块、成稿的阅读视图和编辑预览都走它。
- **深色主题**：作者写的块自带浅色。宿主 body 带 `data-ds-dark-theme` 时，从外面给 iframe 加 `invert(0.88) hue-rotate(180deg)`：白底变深、文字变浅、色相不变，切换主题不用重载。
- iframe 元素和它的文档都固定为 `color-scheme: light`。两边的配色方案不一致时，浏览器会给 iframe 画不透明底，反色后就成了一圈灰带（截图对照时发现）。
- 卡板摘要把每个块记为「[图示]」，不露源码。

**同日第四轮（0.4.12）。** 在 3080 上再看一遍之后：

- **画布选择改成最后一个标签后的「＋」**，和侧栏的 ＋ 一样。标签条不再撑满（`flex: 0 1 auto`），＋ 就跟在标签后面。按钮只有图标（可访问名为「打开或新建画布」），点开还是同样的画板列表加「新画布」。靠近右边缘时，列表改为向左展开（打开时测量）。
- **分区可以删除。** 悬停时，分区右上角出现 ×。删掉的只是分区（一个 `lanes` 补丁），卡片都留在原位，toast 会说明这一点。
- **连线视图的工具浮在画板内。** 右上角的浮层固定显示合计（「2 个分区 · 1 条线」）和「＋新分区」。选中后的操作（对谈、写成稿、删掉这条线、取消选择）挪到底部居中的浮动条，只在有选中时出现。原来画板下方的整条栏删掉了。
- **分区标题做成标签块。** 显示和编辑是同一个框（22px、layer-1 底、圆角 6）。编辑时加品牌色描边和一圈淡光晕，整个分区也描边。Esc 取消；没命名的分区用「未命名分区」作占位。
- **⋯ 图标本来就是宿主的** `IconEllipsisOutlineMedium`。原先画成 13px，宿主默认是 16。现在只把图形放大到 16，按钮仍是 22/24px 的框，悬停方块和选中框保持一致（用户定的）。
- **分类面板的文案和排版重做。**
  - 标题是「分类 只作用于这块画板」，存储路径挪进 tooltip。
  - 每行显示张数、一个小「内置」标签和一个幽灵按钮「停用」。
  - 两条规则写成分隔线下的短列表：改名只改显示；停用会把该分类的卡一起归档（并说明怎么留住它们）。
  - 内置分类的默认名显示在 placeholder 里，所以按正文色显示。浏览器默认的灰在深色下太淡（截图对照时发现）。

**后续（0.4.13）：标签条不画滚动条。** 标签条改成按内容宽度之后，macOS 设成「始终显示滚动条」时，亚像素级的溢出会在两个短标签下面画出一条滚动条。现在标签条隐藏滚动条（`scrollbar-width: none`），但仍能滚动：鼠标竖向滚轮转成横向（原生非 passive 监听，只在溢出时生效），触控板横扫照旧，当前标签变化时自动滚进视野。

**后续（0.4.14）：Agent 看得见画布的分类了。** 用户建了「人物」「世界观」，Agent 落卡仍然全进灵感。原因有两个：`canvas_propose_card` 的 `kind` 是五个内置分类的 enum（定义在启动时注册，那时还没有打开的画布，所以永远列不出自建 id）；也没有任何工具能读板。现在 `canvas_read_board` 列出分类目录（id、名称、未归档卡数、是否停用）和每张卡一行（id、分类、状态、标题；归档卡默认只计数，按需列出；上限 200 行，可按 `kind` 过滤）。`kind` 改成开放字符串：存储本来就按当前画布校验，校验不过时现在回答这块画布可用的 `id（名称）` 列表，而不是只回一个 `invalid-name`，猜错一次就能自己改对。内置分类的名称在宿主侧固定写中文，与工具描述一致——内置分类存的 label 是空串，本地化在客户端。同一轮里，卡片名（面包屑、标签页标题、详情标题、给模型的卡片清单）经 `plainInline` 去掉行内 markdown 标记，`**雨夜**` 显示为 雨夜；行级标记保留，因为非文档卡上的 `# x` 就是它的原文。带类型的字段、模板、Agent 提议类型（「人物卡」那个需求）是下一步，不在这一轮。

## Alternatives considered

- **编辑器工具栏放在底部，或做成浮动工具栏。** 不采用：用户选了顶部吸顶栏。长卡片上它一直可见，也有空间容纳更多插入类型。
- **把粗细存在每个点的 `w` 上。** 不采用：`w` 已经承载按速度推算的压感，上限是 `PEN_MAX`，无法再放大。按笔画存一个倍率，压感和粗细互不干扰，旧数据也不用动。
- **新卡只保留单独一页这一条路径。** 不采用：这正是用户说的突兀跳转。那一页仍可经「展开」进入。

## Consequences

- 卡板结构：笔画可能带 `size`。不认识这个字段的读者按「中」渲染，向后兼容。
- `appendStroke` 必须带上它保留的每个笔画字段。它原先会悄悄丢掉 `size`，是测试发现的。

## Testing

- `tests/draw.spec.ts`：
  - `normalizeDraw` 保留 thin/bold，丢掉 medium、缺失和未知值；
  - 细比中窄、粗比中宽；
  - 没有 size 时按中画。
- `tests/detail.client.spec.tsx`：
  - 粗细组只在拿起画笔时出现；
  - 「中」的笔画不带 `size`，「粗」的存 `bold`；
  - 新画板沿用上次选的粗细。
- `tests/block-editor.client.spec.tsx`：工具栏顺序、拖入到缝隙、非图片拖入、图片预览。
- `tests/tab.client.spec.tsx`、`tests/strip.client.spec.tsx`：虚线格就地草稿、展开、⏎ 建卡、空卡板的虚线格。
- `tests/html-blocks.spec.ts`：切块、跨行配平、自闭合 svg、未闭合、围栏、缩进与行中标签、摘要标记。
- `tests/manuscript.client.spec.tsx`：成稿里的整块 HTML 进沙箱 iframe（带 CSP），不显示源码。
- 516 个测试通过。
- `tests/link.client.spec.tsx`：删分区只发 `lanes` 补丁，卡片都留在原位；分区名里按 Esc 是取消；只读画板不显示删除分区；合计从右上浮层读。
