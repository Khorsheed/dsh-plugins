# Agent Note：运行记录说得出它跑了什么、交了什么

Status: implemented

## 问题

用户 2026-09-18：**「看不到每个 agent 的运行过程以及结果」**。

运行记录详情（I5·T67）把一格的产物按路径列出来，底下一句诚实而认输的话——*预览和下载要宿主的文件服务，这个 tab 还没有*——再给一扇通往转录的门：打开子会话，选手的。于是这一页点得出这次 run 产生的每个文件的名字，一个也打不开；也点得出在这格上干过活的两个 agent 中的一个。

两半都比看上去小。**字节**在宿主这边早就够得着：判官台读的就是同一个 attempt 目录下的 `archive/workspace/`，拿它做去指纹材料——缺的从来只是一扇门。**判官的转录**也早就是一条宿主会话：编排器从有判官那天起就记着 `{kind: 'judge', …, childSessionId}`——「为什么判成这样」只能从判定那一行 `evidence` 里猜，是因为没有按钮，不是因为没有记录。

## 决定

给两件本来就在的东西各开一扇门，外加收窄一个一直在悄悄回答另一个问题的回落。

- **`cellArtifact(runId, missionId, attempt, path)`** —— 一个只读的 Remote 动词，附件那几行就此变成打开它的控件。`stage1.md` 在它被列出来的地方读。只认文本扩展名（`md / json / txt / yml / yaml / log / jsonl`），256 KB 上限并把截断说出来，目录返回条目（`archive` 与 `probe-verdicts` 这两件产物**本身就是目录**，一行点了没反应比没有这行更糟），其余一律**按名字**拒，并把扩展名写进那句话里。
- **越界判两次，两次都不可省。** 第一次是**字面**的，不碰磁盘，所以 `../` 不论目标在不在都按越界拒——调用方不能从「越界」与「不在磁盘上」的差别里读出「这个文件存不存在」。第二次判两侧的 `realpath`，抓的是字面判看不出的那一种：归档**里面**一条指向外面的软链，导出过程可以在没人有此意图的情况下留下这种形状。
- **有意不去指纹。** 这一页的页眉本来就写着对比组，在这里刷掉只会挡住正在排查的人、保护不了任何人。盲的那份是判官台的，读同一批文件，过这个 run 自己的去指纹表——去指纹仍然只有一份实现。
- **原样贴出，不按 markdown 渲染。** `stage1.md` 在这页是**证据**不是文档。渲染器会把写坏的标题或没闭合的围栏悄悄吞掉，而那在这页是发现，不是瑕疵。
- **判官每一轮都拿到选手那颗按钮。** `judgeSessionsOf` 把 `kind: 'judge'` 注解投影成行——条件、模型、采样、自评标记——每行一颗「打开判官会话」。委派没起成的那一轮**保留**，按钮禁用、错误原文写在旁边：「这一轮判官没跑起来」是个答案，删掉这行会读成判官根本没判过。
- **选手那条回落现在真的指选手。** `refs.sessions` 为空的格子回落到最后一条带 `childSessionId` 的注解，而带它的有三种：`delegation`、`readiness`、`judge`。于是每一个走到这条回落的已判格子，打开子会话开的是**判官**那条；被拒的格子开的是就绪探针那条。从来没有失败过，只是答了另一个问题。`cell-detail.ts` 与 `read.ts` 现在都只读选手自己那几轮。
- **报告里的一个数是通往它那些记录的门。** 配对表每一侧的数点开，落到 运行记录 上那个（题目 × 对比组）。这个数是**这个 run 各次重复的均值**，所以跳转只报出这一对，由记录列表去解它到底是几条：**一条**就把它的详情打开，**多条**就把列表留在那儿，上面一枚说清缩到了什么、可以清掉的提示。五枚状态筹码在缩窄后按缩窄的那一群计数——计数与行必须描述同一个总体，否则会出现「失败 3」压在一张空列表上。

## 容器轮什么都不需要做

文案的计划是先验证宿主能不能把磁盘上的 sub-dsh 会话**认领**下来（把目录拷进 `<DSH_HOME>/sessions/_no-cwd/<id>/`，三问，哪一问不过就退回自渲染时间线）。在活的 3171 实例上对 pilot D（`run-20260918054718-8o0o`）实测，三问都不成立了——因为那条转录是**构造上**的宿主会话，不是一件待收养的东西：

1. **不重启 `session/list` 会不会出现** —— 两个容器轮选手此刻就在列表里，`origin: "subagent"`，`cwd: /private/tmp`。
2. **开不开得出** —— 前提（「没经过 session/create 的会话」）不成立：子会话是 provider 建的，`local-agent-dsh` 的 session mirror 逐轮把 sub-dsh 的事件并进去，`persistChildSession` 落盘。按 subagent 地址调 `session/page`，`dsh-full` 回 **98 条**、`dsh-lean` 回 **88 条**——消息、`tool/call`、`tool/result`、`todo/write` 都在；判官两轮同样开得出（18 与 29 条）。**单独**按 `kind: 'session'` 寻址会被宿主拒：*subagent Sessions require their durable parent address*——这正是抽屉把 id 交给 `sessions.open`、由宿主自己的控制器去解父地址的原因。
3. **workspace-attach-failed** —— 任何载荷里都没有。容器轮的宿主侧 cwd 是 `/private/tmp`，宿主上存在。

所以不拷贝、不重记 `childSessionId`、也不自渲染时间线。那条路上唯一真实的缺口是回落指向了判官的会话，已在上面修掉。

## Alternatives considered

**按文案计划把 sub-dsh 会话目录拷进宿主会话树。** 因实测而否，不是因偏好：那条会话已经在那里了。拷一份会造出**第二条**内容相同、没有主人的会话；而 `<DSH_HOME>/local-agent/dsh@<scope>/` 会被 provision 重写——计划里「拷贝而不是软链」这条规矩，正是为一次并不需要的拷贝定的。

**自己渲染转录（`cellTrajectory` + 时间线），也就是计划里的退路。** 没做。它的前提是三问里有一问不过，而三问都过了。一份转录的第二个渲染器就是它第二个可能出错的地方，何况它得把宿主视图已经画好的思考块、工具卡与用量统统重写一遍。

**把 `stage1.md` 按 markdown 渲染。** 否：见上——在这页，写坏的围栏就是那个发现。

**嗅字节而不是信扩展名。** 否。开头恰好可打印的二进制，正是会把面板灌满噪声的那一种；而按名字拒绝，理由永远打得回给读者。

**只判解析后的字符串。** 否，不够（归档里的软链能过）——而只判 `realpath` 在另一头也不够：它在路径不存在时先失败，会把一次穿越尝试报成「不在磁盘上」。所以两次都判。

**下载，或图片 / 二进制预览。** 按文案自己的那一行属于不做；而下载恰恰是真需要宿主文件服务的那一半。这里没有任何一处写、删，或交出格子之外的路径。

**在点击那一刻就把报告的格子解成一个 mission id。** 否：一个配对格子指的是这个 run 有几次重复就有几条记录，解它等于替读者挑了一条。由列表去解，并说清是哪一种情况。

## Consequences

- `record.filePending` 这个词条从中英两份词表里删掉了——它道歉的那句话不再为真。
- 这一页现在会把某个 harness 自己的产出**不刷指纹**地放到屏幕上。在这页是对的，隔壁一页就是错的；两处的读是有意写成两个函数读同一批文件，盲的那个仍然走 `deidentify`。
- 判据 × 对比组表（T54，正在 `fix/eval-report-per-criterion` 上）每条样本都带 `missionId`，它的格子接同一套跳转——`focusRecords` 收那一对，带 id 的调用方直接要 `openCell`。这行接线是 graft 时的一行，**不在**本分支里：本分支基于 `main`，那张表在 main 上还不存在。
- `judgeSessions` 是 `EvalCellDetail` 上新增的必填字段；手搓 fixture 的地方要补上。

## Testing

`packages/eval`：909 → **916 个测试、50 个文件全绿**（`pnpm build && vitest run`）。

- `tests/cell-artifact.spec.ts`（新，15 个）：`isInside` 的前缀陷阱（`/a/bb` 不在 `/a/b` 下）、`extensionOf` 对点文件的判定、整篇文本读出、字节上限连同那句说明、目录列举、按名字拒掉的二进制、穿越在目标**存在**（同 run 另一格的 `stage1.md`）与不存在时**都**被拒、绝对路径按形状被拒、两种缺失、没有数据根目录时的拒绝、服务面的转发——以及 `judgeSessionsOf` 保留没起成的那一轮，同时不把 `readiness` 或 `delegation` 当成判官轮。
- 同一份文件钉住回落的修复：一个**完全没有 refs** 的已判格子答 `childSessionId: 'player-1'`，不是它之后跑的那轮判官；而判官那轮在它自己的名下被报出来。
- `tests/MatrixCells.client.spec.tsx`（+4）：点开附件时带的是**当前**那次 attempt（重跑是另一个目录，同名文件是另一个文件）、再点一下收起、目录的条目走同一扇门、拒掉的二进制把理由与大小印出来、判官那几行开得出宿主会话而没有会话的那一轮按钮是死的。
- `tests/Report.client.spec.tsx`（+2）：两次重复的那一侧落到记录列表、顶着提示、第三条记录被滤掉、**没有**替读者打开任何详情，清掉提示后它回来；只有一次重复的那一侧直接把那条记录打开。
