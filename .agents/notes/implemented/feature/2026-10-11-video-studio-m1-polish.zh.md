# Agent Note: 剪辑台 M1 收尾——成片/原始双视图、垫乐、缓存清理、多段连续录音

Status: implemented

## Problem

真实材料用出四个缺口，每个都不大但都在主路上。(1) 文稿里剪掉的内容永远以删除线杵在那——两百刀之后页面上的疤痕比稿子还多，而且没有办法按「成片的样子」通读。(2) 节目设置里有 `bedMusic`（垫乐），但导出从没混过它。(3) 全局配置里有 `cleanupDays: 30` 却没有任何代码读它——缓存无限增长；自从 ASR WAV 变成面板播放器的音源之后，这个问题更实在了。(4) 录音笔会暂停再继续：一期节目到手的可能是好几个文件，而数据模型只认一条参考录音。

## Decision

**双视图，默认干净。** 文稿 tab 默认落在「成片」：已剪的内容消失、时间码是成片时间、点一句从这句播放、只有还没拍板的提议保留虚线框。「原始」视图保留完整的审计面——带来源样式的删除线、按来源过滤、图例、停顿徽章、点击恢复。开关在统计行；播放器的剪后/原声轴保持独立，主力循环（看标记、听成片）不受影响。在成片视图里剪掉 = 文字直接消失，所以配一个 6 秒的撤销浮条。查找与替换以成片为准：`findOccurrences` 默认跳过已剪内容，除非调用方传 `includeRemoved`（原始视图会传——被剪掉的句子还能搜出来恢复）。

**垫乐真的混。** 导出时垫乐铺在整期下面（MP3 和 MP4 都有）：输入 `-stream_loop -1` 循环（导出执行器新增 `loopInputs`）、按成片长度截断、固定 0.16 增益、以人声为 sidechain 键做 `sidechaincompress` 闪避。片头片尾的时长计入进度和垫乐长度。垫乐文件找不到时跳过，不出错。

**清理真的跑。** `sweepCaches()` 每次启动跑一次：工程缓存（ASR/代理 WAV、peaks、声纹缓存、filter 脚本——全部可重建）在最后一次成功导出 `cleanupDays` 天后删除。`project.json` 永不动。

**多段连续录音。** 导入时勾「连续录制」（或 `video_import` 带 `continuous: true`）把这批录音按路径顺序拼成一条逻辑参考：`project.referenceParts = [{sourceId, startSec}]`，编辑时间轴就是拼接轴。ASR WAV 由各段拼接生成（每段先做格式归一），转写、分人、播放器、`audioChunk` 全部无感。每段各自和画面对齐（墙钟上的停顿不在拼接轴上），存为 `source.partOffsets`；`mapFramesToVideo` 在接缝处切开保留区间、每段按自己的偏移对齐帧网格。文稿在跨越接缝的第一段前画一条虚线分隔（「第 N 段 · 继续录制」）——包括接缝正好落在段落中间的情况，拼接点可以在一句话中间。已有文稿后锁定，不能再改拼接。

## Alternatives considered

- **视听共用一个开关。** 否决：主力循环是「看原始标记 + 听剪后」，校稿是「看原始 + 听原声」；视图和播放模式一合并，两个组合都没了。
- **选区操作用底部横条（短暂上过）。** 已换成贴着选区的浮动气泡——横条离文字太远，还和播放条抢位置。
- **每段各管各的时间轴（虚拟轴）。** 下游（编辑、播放、字幕）要永远逐段换算。导入时一次拼接只留一条轴；代价就是上面的接缝处理。
- **复用 filtergraph 标签靠 ffmpeg 隐式 split。** 它会悄悄丢掉 concat 的后几条腿——6:00 的工程导出成 117 秒。现在只要多个保留区间消费拼接参考，就显式 `asplit`，并有测试钉住图谱形状。
- **垫乐音量做成设置项。** 暂缓：固定 0.16 + 闪避覆盖默认场景；逐期调节是声音 tab(M2)的位置。

## Consequences

- `Project` 新增 `referenceParts?`、`Source` 新增 `partOffsets?`，加上之前的 `EditKind: 'text'`，全部是增量字段，旧版本读到也安全。`snapToFrames` 被 `mapFramesToVideo` 取代（测试已移植）。
- typert 分析器拒绝「带默认值但没写类型」的公开方法参数（`now = Date.now()` 必须写成 `now: number = ...`）——它在 tsc 之前就把 gen-typert 弄崩。
- 构建卫生，这一节连着两次：把构建输出 pipe 进 `grep -c` 会在 gen-typert 崩溃时报出「0 个错误」的假绿；`tsc -b` 的增量缓存漏掉过一个未定义变量。现在的关口：完整构建看退出码，缓存可疑时再补 `tsc -p tsconfig.host.json --noEmit && tsc -p tsconfig.client.json --noEmit`。

## Testing

`tests/core.spec.ts`（19 个）：`mapFramesToVideo` 的帧网格对齐和逐段偏移接缝拆分、audioGraph 的垫乐混音与显式 asplit、清理扫描的删/留矩阵，加上此前的改字与时间轴用例。3197 实例实测：真实录音切成两段（m4a 32 kHz + wav 48 kHz），连续导入带段标、拼接转写覆盖到 6:00 联合轴末尾、接缝分隔条、跨缝播放、导出 MP3 精确等于保留时长（297.161 秒 = 360 − 62.84 的剪切）。
