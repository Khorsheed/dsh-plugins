# Agent Note：图书馆——路线改成竖排课程轨道，站不再上锁

Status: implemented

## 问题

路线原来是三列之字形：每行 84px，标签 110px 宽、12px 字。中文站名一长就折成三四行、互相挤在一起；每站只显示 已过关 / 当前 / 锁定，看不出讲义有没有写、考点掌握得怎样。站还会上锁，前一站没过关就进不去。用户想要多邻国那样想去哪站就去哪站，路线只显示进度，不拦人。

## 决定

与用户对照 `proposals/prototypes/library-slimming.html` §5（方案 A）和决定 D6 定论：

- **竖排轨道**（`client/views/path.tsx`）：一站一行，站名完整显示，按目录的部分分组。顶部一行进度：过关几站、掌握几个考点。
- **四种状态**（`stationStatus`）：已过关（绿底对勾 + 最好成绩）/ 学习中（琥珀色描边：考过，或有考点不再是未考；显示待订正题数）/ 已备课（蓝色描边：讲义已写）/ 未开始（灰色：显示考点数和章节）。开始学过的站用小圆点显示各考点的掌握情况。
- **只推荐下一站，不强制**：第一个没过关的站加光晕并展开一张卡片。「开始学这一站」打开导读；「接着学这一站」打开讲义；有待订正的题时多一个「去订正 N 题」。
- **D6，不上锁**：采用路线时，没过关的站一律设为 `current`，存储里的 `locked` 读出来也当作 `current`。任何一站都能学、能考，过关就记为完成。`unlocked` 列表现在总是空的，判分结果里的下一步提示自己说出下一站。

## 考虑过的方案

- **保留之字形（方案 B）、把圆放大**：否决。只有少数几站放得下站名，考点掌握情况根本放不下。
- **保留锁、加一个跳过**：用户否决。路线应该显示进度，不拦人。

## 后果

- `unlockReady` 和出题时的上锁提醒现在不会再触发。为兼容旧数据暂时保留，之后可以删除。
- 旧的之字形 CSS（`.path*`、`.disc`）已不再使用。

## 测试

190/190 全绿。与锁相关的断言按 D6 改写：采用后所有站都是当前、没有站被解锁、给后面的站出题不带上锁提醒。轨道在侧栏 fixture 中按 420px、深浅两种主题核对过：部分分组、已过关 / 学习中 / 未开始三种行、一个选读站，以及带「去订正」的下一站卡片。
