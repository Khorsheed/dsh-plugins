# Agent Note: 画布对谈改为引用进主会话输入框

Status: implemented

## Problem

从 M2 起，画布的所有聊天手势都走 side-chat 插件：透镜条（七个透镜按钮加「就此提问」）、评论「追问」、「生成文章」，以及卡片页的「就这张成稿」。每一个都开一个上下文独立的第二个 Agent 会话。2026-09-27 走查时，用户指出三个问题：

- 用户真正关心的对话在主会话里，side chat 把它劈成了两半。
- 透镜一排让选中后的底栏成了板面上最拥挤的地方。
- 卡片静止时就挂着一堆控件（选择框、⋯、空的 💬、铅笔），和文字抢注意力。

用户选定用一条路取代上面这些：把卡片原文放进主会话的输入框，由用户把话说完。

## Decision

**所有聊天手势都引用进当前会话的对话输入框。** 选中后的「与 Agent 对谈」「开始写作」、卡片页顶栏的同名两个按钮、Agent 评论旁的「追问」，都经宿主输入的 `setDraft` 写入一段 Markdown，从不自动发送。用户看过这段引用、补一句，再自己发出去。

- **引用块**（`src/client/quote.ts`）先是卡片原文的引用块，后面跟一行出处：画布标题 · 板面上的分类名 · 卡片 id。这个 id 就是主会话 `canvas_*` 工具接受的句柄。
- **边界。** HTML 卡只引一个指针（标题和长度），从不贴整页。超过 1200 字的卡截断，并注明全长。评论只带最新 8 条。
- **「开始写作」** 就是同样的引用再加一句写作指令（`talk.writeText`），不是另一种模式。
- **合并。** `setDraft` 会替换整个草稿，所以写入前先读再合并：用户已经打的字保留，引用块隔一个空行接在后面。reader 包和 quote 包也是这条规则。
- **接入** 按结构取：`sessions.scope(id).get('conversation').input.for(scope)`，在 try/catch 里校验 `getSnapshot`/`setDraft`。没有输入框时这些入口隐藏；写入被拒时弹提示，不静默失败。

**板面在可见时轮询。** 没有了 side-chat 的回合监听，客户端不再知道 Agent 回合何时结束。改为：`document.visibilityState` 为 `visible` 时，标签页每 4 秒调一次 `refreshBoards()`（共享 rev 的 `touch()`）。两处读板 effect 在版本不变时都保留原对象，所以安静的一拍不会触发重绘。

**卡片减负。**

- ☐ 选择框和 ⋯ 只在悬停或 `:focus-within` 时出现；`(hover: none)` 下常显。
- 评论徽标只在卡片有评论时显示。
- 卡片上的铅笔去掉了：点开卡片就是编辑。
- 数量为 0 的分类 chip 降到半透明，激活或悬停时除外。

**side-chat 的服务端路径这次提交先保留。** 客户端只是不再调用它。`askAgent`/`chatStatus` 动词、side-chat 工具定义和透镜提示常量在下一个提交里退役，这样这次提交是一个可以单独审阅的纯 UI 改动。

## Alternatives considered

**保留 side chat，只去掉透镜一排。** 不采用：用户的主要不满是对话被劈成两半，不是按钮多少。

**引用后直接发送。** 不采用：一张光秃秃的卡不是问题。留在草稿里，用户能说清自己想要什么，而且模型收到任何东西之前用户都先看过。

**「与 Agent 对谈」做成下拉，选目标（主会话 / 侧边对话 / 复制）。** 用户明确不要下拉。复制和侧边对话仍由引用插件的文本选区菜单提供。

**对主会话继续做回合监听。** 宿主没有给插件稳定的回合状态接口可盯。版本轮询很便宜、只在可见时运行，还能顺带接住另一个浏览器标签页里的改动。

## Consequences

- 一块画布不再有专属的持久 Agent 上下文。Agent 对画布的了解来自主会话的画布工具，以及用户引用进去的内容。
- 透镜不再是按钮。它们的意图现在落在用户接在引用后面写的那句话里。
- 常驻的 4 秒轮询取代了回合监听。代价是每一拍读一次版本，且只在标签页可见时发生。

## Testing

- `tests/quote.spec.ts`：引用块与出处行、HTML 指针、长度截断、手绘行与最新评论窗口、卡片顺序、评论引用、草稿合并。
- `tests/tab.client.spec.tsx`：选中 →「与 Agent 对谈」/「开始写作」按板面顺序引用；「追问」引用那条评论；没有空的评论徽标；没有铅笔；4 秒轮询在可见时运行、隐藏时停止。
- `tests/detail.client.spec.tsx`：顶栏两个按钮、追问引用、写入被拒的提示、没有输入框时入口隐藏。
- `tests/link.client.spec.tsx`：连线面按组引用走同一条路径。
- 在临时实例上截图核对：静止板面、卡片悬停、精简后的选中底栏、引用落进主输入框并弹出提示。
