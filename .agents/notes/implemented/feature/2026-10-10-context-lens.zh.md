# Agent Note: Context Lens request and timing workbench

Status: implemented

## Problem

原请求明细能展示采集数据，但缓存下降、重复提示词与昂贵工具交互不易比较。确认稿还暴露了耗时舍入不一致和主、子 agent 混算的问题。

## Decision

包、目录、bundle 行与侧栏 kind 改名为 `context-lens`（`@khorsheed/dsh-context-lens`）。保留 `requestInspector` 服务与 Remote 命名空间，兼容已有作用域读取方。这是安装身份变更：已有部署必须替换旧直接依赖与 bundle 行；两个包同挂会重复注册服务。本次不发布 npm。

保留用户确认的带边框四格、等宽数字与原耗时配色。轮次步进与最新按钮同步会话滚动。可横向滚动、拖动的会话地图显示保留请求的输入与缓存数据；`getSessionTrend(sessionId, filter)` 只返回请求头，并沿用作用域过滤、留存与 generation 元数据。

请求详情依次为真实缓存用量、本次交换（新增输入与捕获输出并排）、上下文构成。可以筛选全文相同且至少 40 字符的重复条目。消息行透出显式工具错误与已知的会话事件来源轮次。长输出、思考默认显示限高预览，展开仍限高滚动；参数值独立展开。

请求列表采用紧凑两行：动作与缓存比例、输入 → 输出与耗时。四项指标分别展示数值、单位和辅助信息。请求标题右侧的 `{ }` 只将下方详情换成 JSON，请求列表和指标仍可用。底栏和未实现的 wire body 占位入口移除；测量口径放到构成区信息提示，回溯不完整状态放在轮次导航旁。

构成区为一个统一边框：类别条、紧凑百分比图例，再接系统/工具/历史/新增各层，包含比例条与原始数量。类别和重复为互斥筛选，只影响明细行。选中筛选自动展开匹配层；重复行保持请求顺序并标 ×N。至少 40 字符的全文精确匹配，只统计首次以后的多余副本，覆盖跨层重复。新增明细默认展开。本次交换的卡片直接显示预览；思考与参数值独立展开，不撑宽面板。

前缀比对读取同一作用域保留的精确分段内容，支持跨轮。追加消息保留旧前缀；替换、删除及工具 schema 变化可见。前缀差异只说明组装事实，不推断供应商缓存失效原因。没有保留上一请求时显示无法比对。

耗时四格与两表只描述所选 agent，所有 agent 仍保留独立可点击泳道。请求内部余量与请求间隙分别列出。工具调用前思考由同请求调用均摊，参数时间归对应工具泳道，执行错误只读显式 `isError`。并发重叠区间由同时活动的片段分摊，并显示说明，使四格与两表可加总。所有时长保留十分之一秒。

## Alternatives considered

**再次改视觉。** 用户看过后否决，保留此前确认的方向。

**模型生成发现或改宿主。** 用户要求只展示可观测数据且不改上游；精确比较与真实 usage 满足该范围。

**主、子耗时直接相加。** 委派已含子 agent 执行，直接相加会重复计时；按 agent 分账保留区别。

**从工具文案猜错误。** 错误合计消费宿主标记；Canvas 自己的明确失败改走宿主抛错路径。

**保留底栏或通过改写请求副本筛选。** 底栏违背确认稿；为筛选重写分段还会改变分母并隐藏原始分组大小。请求内切换和仅筛选明细行同时保留导航与测量含义。

## Consequences

新安装身份在生产替换前需要迁移。旧侧栏 kind 可能显示宿主的不可用兜底。采集仍为拉取式，受已有留存预算限制；不编造未采集或已淘汰数据。前缀只给短预览，完整请求仍可展开。

回归覆盖并发对账、两表加总、来源轮次、稳定消息 ID 下的内容变化、作用域过滤的走势读取、Remote 参数数、导航与输出展开。实际组件使用合成数据在桌面和 390px 下做视觉自检。

首次在 main 基线 `84399e6a` 验收时，全仓 build/test 通过，但最后的打包门禁失败：全量 `gen-typert` 把 game 的 `MessageSourceMap` 增补带入 Canvas 诊断声明，被家族边扫描误判为依赖。mainline 已在 `43c56cb9` 修复扫描器（见[修复记录](../bug-fix/2026-10-10-pack-dist-typert-face-exemption.zh.md)）。同步该修复后，`pnpm gate` 以 464 秒通过全部 16 步：全仓构建、测试及 39 个 bundle tarball 验证，其中 Context Lens 137 项、Canvas 620 项、脚本测试 327 项。合并阻塞已解除；冷安装验证仍由 CI 执行。

生产迁移使用显式 `deploy:3080 --replace OLD=NEW` 流程（[决策](../process/2026-10-10-deploy-package-replacement.zh.md)），禁止两个身份同挂。上线结果在 canary 验证后另行记录。

设计稿对齐的回归验证覆盖多余副本计数、相同预览而全文不同、互斥筛选、总量与交换不变、JSON 模式导航。可复现的 `packages/context-lens/examples/workbench/` 预览使用合成数据和实际组件；800px 与 390px 深浅色检查均无横向溢出。
