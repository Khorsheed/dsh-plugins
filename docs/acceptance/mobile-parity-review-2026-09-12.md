# Mobile 一致性审查 — 2026-09-12

验收人：Codex · mobile 0.1.0 开发线 · 宿主 0.1.5-rc.1（183f08e9c6）。

## 环境

延续独立 worktree 和 3181/3182 测试服务，Node 22、pnpm 11，标准 tarball 安装。生产 3080、宿主源码和其他插件源码均未修改。测试 profile 增加 local-agent-kimi 0.1.0-rc.6；Codex、Claude Code、Kimi 在此独立环境均未登录。

## 逐项结果

本次审查覆盖 mobile 实际使用的宿主与插件入口，并非所有社区插件的完整功能认证。

| 对象 | 发现及处理 | 证据 |
|---|---|---|
| Room 邀请 | 原先存在两套表单，移动版缺少首个任务、目录与原错误提示。删除移动修改实现，转发到原 Room 邀请按钮，只调整样式。 | 「＋」实际打开原表单；字段包含 Provider、称呼、首个任务、角色指令、工作目录，三个 Provider 动态出现。 |
| Room 邀请请求 | 保留原字段、省略空目录、沿用原错误映射。 | 浏览器拦截请求（未实际派发 CLI）：`provider=kimi-cli`；keys 为 sessionId/provider/name/instructions/firstTask；模拟 duplicate-name 后原表单显示“名字已被占用”。 |
| Room 编辑 | 原移动表单会重传未修改字段，缺少目录编辑。成员设置快捷入口改为打开原成员页中对应成员的编辑表单。 | 实际测试 Room 角色修改成功；请求仅含 sessionId/name/instructions，不包含未改的 rename/cwd。 |
| Room 移除/停止 | 原移动面板额外禁止运行中移除，与 Web 不同。移除操作统一留给原成员页及其确认；停止使用原运行记录/子会话入口。 | 源码核对 MembersView、MemberCard、RoomRunView；mobile 名册服务现只调用 getState，已无通用 mutation 方法。 |
| 排队消息 | 原移动面板缺少待确认请求计数去重，且编辑判据与 Web 略有差异。现按 rpcId/requestId 去重，使用 row.text 判据；行消失或变成不可修改时退出编辑。 | 行为测试覆盖待确认计数、附件不可编辑、行消失、准确 queue ID 的 steer 请求、插件缺失回退。普通会话仍使用原 QueueDock。 |
| 消息动作 | 仍调用消息所属原按钮，不复制 message-tools 数据修改或确认逻辑。 | 用户编辑打开原插件编辑框；助手菜单使用对应 turn 的复制/反馈/分支动作。保留原禁用状态与未识别渲染器动作。 |
| 输入与权限 | 编辑器、发送、停止、模型、权限、附件及命令的业务回调由官方组件负责。mobile 只归并入口、放置圆环并在提交确认后失焦。 | 六组窄屏检查圆环在卡片内、Send 44×44、无水平溢出；模型仍有文字。提交失败与新草稿不主动失焦的行为测试保留。 |
| local-agent | 成员子会话使用真实 childSessionId；保留原输入框与运行状态。修正失败任务在移动名册被显示成普通闲置状态的问题。 | 行为测试确认原 sessions.open 收到准确 child ID；真实 CLI 未登录，未派发任务。 |
| 目标/任务/TaskPilot | 保留原插件槽位、回调及侧栏详情，未新增执行逻辑。 | 源码核对 RoomComposer/RoomDockCapsules 与 TaskPilot slot 注册。Room 在 Web 也接管普通 dock；并非所有普通会话胶囊都会出现在 Room。这是原组合行为，不能表述为移动端已完整验证所有胶囊。 |
| 导航与目录 | 会话打开/新建仍使用官方 workspace/sessions 服务。移动端工作区表单提交电脑路径给原 owner，Room 表单则使用其原目录选择回调。 | 两类目录入口用途不同，均未把手机本地目录当作 Host 路径；成员页保留作为未知快捷锚点的回退。 |

## 限制与后续验收

- 已消除本次发现的重复表单和队列状态差异；这不等于证明全部宿主/插件行为绝无差异。快捷入口仍依赖校验后的公共槽位与语义 DOM，未来版本改变结构时回退原成员页；未知对话框不会套用 Room 样式。
- 移动端预期的交互差异包括发送后收键盘、长按菜单、底部面板、标题元信息、隐藏已识别的桌面工具及默认轨迹入口；数据与执行语义继续由原组件负责。桌面模式不应用移动样式。
- Codex、Claude Code、Kimi 的真实派发、子会话往返和 TaskPilot 完整生命周期仍需已认证环境验收。本次邀请首任务测试拦截了请求，没有将模拟响应当作实际执行证据。
- 真机键盘动画、系统文字选择与长按的协调、系统大字/缩放，以及真实网络断线恢复仍需要手机复测。未进行 main 合并、3080 部署或 npm 发布。
