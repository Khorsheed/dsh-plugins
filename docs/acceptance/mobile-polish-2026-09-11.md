## 19:19 手机暗色反馈修正

用户截图证实旧版暗色模式出现白底白字，不能记为视觉通过。根因是配色别名在 html 提前解析到白色 fallback，以及不存在的 bg-l1 变量。别名已移至官方主题变量所在的 body，背景采用官方 floating-fill / module-platform。加号、附件按钮改为透明底 40×40 触控区；搜索和编辑器提示使用次级文字色。

Chromium 420×810 移动视口加载隔离测试服务，注入本轮最终 CSS；原生 bridge 仅以 capability stub 提供扫码按钮。逐页截图核对首页、已有会话和新建页，均执行浅色 → 暗色 → 浅色切换。实测暗色浮层背景 rgb(44,44,46)，主要前景 rgb(249,250,251)；浅色为白底、rgb(15,17,21) 前景。两个工具按钮背景透明且宽高均 40。未改 Host 主题偏好，未提交对话消息。该验证不涵盖 iPhone 键盘、相机或系统主题事件，仍需用户手机反馈。
