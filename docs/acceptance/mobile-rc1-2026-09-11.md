## 卡住的地方

- macOS 辅助功能/屏幕录制权限未就绪，原生模拟器画面检查未完成。只能声明 native build/install/launch 通过。
- 无已配置私网 HTTPS 与签名真机，本轮没有蜂窝网络、真实切网、键盘/安全区、附件选择/上传、后台恢复或多端竞争实测。
- 未验证 message-tools 编辑/撤回、local-agent 成员、文件预览等社区组合；基础包保留官方渲染器不构成这些组合已经可用的证据。
- 全部受保护 HTTP/上传/资源/WS 的认证矩阵尚未覆盖；当前认证结果仅指 mobile 握手。没有配对、逐设备撤销、APNs、系统分享或设备 Keychain 凭据。
- 依赖变更按受控重启和页面刷新处理，不通过 host fork 或修改兄弟插件伪造热卸载。恢复桌面模式可用 `?mobile=0`；重新开启用 `?mobile=1`。
- dev link 移除后，源包 node_modules 链接被清理；pnpm 的乐观重复安装跳过了恢复。使用 `pnpm install --no-optimistic-repeat-install --ignore-scripts --frozen-lockfile` 恢复并重跑构建/测试。产物验收使用 tarball，避免这种链接耦合。
- 完整发布门禁、生产 3080、RC 升级矩阵与回退演练尚未完成。提案保持 in-progress。
