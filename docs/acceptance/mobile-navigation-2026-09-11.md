- 扫码需要电脑提供已有登录链接的二维码，当前未提供 Host 自动生成入口；本次仅在忽略的私有测试目录生成当前测试实例二维码供真机手测，不提交带凭据图像。不宣称一次性配对或逐设备撤销。
