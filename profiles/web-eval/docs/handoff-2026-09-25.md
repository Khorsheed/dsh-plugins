## 6. 配方

**合并态验证**（主检出的 node_modules 是旧的、缺 js-yaml / react 链接，别在主检出跑测试）：

```sh
git worktree add -b docs/<t>-accept ../dsh-plugins-wt-verify-<t> main
cd ../dsh-plugins-wt-verify-<t>

for p in eval eval-tool datasets datasets-tool; do pnpm -C packages/$p test; done
pnpm --config.verify-deps-before-run=false test:scripts
node_modules/.bin/tsc -b --noEmit packages/eval packages/eval-tool packages/datasets packages/datasets-tool
```

验证 worktree 顺手当文档 worktree：在里面改 iterations / ui-spec，只 `git add` 明确路径，提交，再**回主目录** `git merge --no-ff`，然后 `git worktree remove` + `git branch -d`。

**冲突预检**：`git merge-tree --write-tree <a> <b>`，两个参数都要是 commit；exit 1 时输出里有 `CONFLICT` 行。

**文档提交**（不跑测试时）：docs worktree + `ln -s <主检出>/node_modules node_modules`（钩子要）；只 `git add` 明确路径（node_modules 软链会被误提交）；回主目录 merge。

**改文档用 python 脚本**：写到 /tmp（heredoc `<<'EOF'`），用 `python3 -c "import sys; sys.argv=['x','<worktree>']; exec(open('/tmp/x.py', encoding='utf-8').read())"` 跑——直接 `python3 file.py` 会报假的 Non-UTF-8 SyntaxError。每处替换先 count 再换（`replace_n`）；`&&` 链里 python 之后接 `|| exit 1`，别让失败后面的 `git add` 跑起来。

**gate**：worktree 里 `pnpm --config.verify-deps-before-run=false gate`。ankh-guard supervise 泳道在高负载的 main 上本来就红（memory `ankh-guard-lane-red-on-main`）；package map 红 = 有人升版本没 `pnpm map:packages`，重生成提交即可；gate 读工作区不读 HEAD，别 stash 别人的改动。

**临时实例**：memory `temp-web-eval-instance-recipe`（四个卡点与绕法）。**从命令行驱动 3171**：memory `eval-instance-rpc-recipe`（token 换 cookie、method 写全名、args 字段名看报错）。

**旧托管 worktree 清理规则**：Agent Note `.agents/notes/implemented/architecture/2026-09-23-dataset-registry.md`，正则 `/worktrees/[0-9a-f]{16}/[^/]+$`，排除 `~/.dsh/state/…`（3182 的）。

**macOS / zsh**：没有 `timeout`；zsh 没有 `PIPESTATUS`、不自动分词（`set -- $var` 不拆）；`cat -A` 不支持；ugrep 对 `.{0,50}` + UTF-8 会挂；`echo` 的第一个词别以 `=` 开头（zsh 当命令名展开）。
