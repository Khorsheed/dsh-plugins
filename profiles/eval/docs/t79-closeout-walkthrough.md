### 4 实验设计 · 方案段

**交互稿**有四点：

- 页首把「要回答的问题」当标题，下面是预期与「怎么算回答了」；
- 规模一句话说清；
- 对比组表只高亮不同处，并就地警告「不同处：2 个…只能描述」；
- 「用哪些题」表有 题 / 考什么 / 怎么判 / 满分 / 看题面 五列；层次上大小有别。

**真机**（夹具草稿 `lean-vs-full-p0`，rev14 字段）：

- 问题、预期、怎么算回答了，都是「小标签 + 正文」上下堆叠，问题没有标题分量；
- 「实验规模与对比变量」是标签 / 值的罗列；
- 对比组表把 sha、harness、模型、端点、作用域、预设、锁全列出来，不高亮差异，也没有「不同处」警告；
- 没有「用哪些题」，位置被「计划网格：计划 1 次」占了；
- 每一段都是等权的描边卡片，整页平铺。

**差距与修法**：见 **P1-4**。另有几处打磨：

- 页脚孤零零的「退回修改 / □ 保留单元」（术语）：P2-2；
- 缺出处行「agent 起草于 …，来自本会话」：P2-3；
- 「规模与花费」只有四个输入框，没有估算作答份数、时长和 token：P2-4（要新算，建议放下一轮）；
- 「怎么判」只有判官一行：P2-5。

**归属**：eval（DesignPage）。
