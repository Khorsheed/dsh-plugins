这个画板的分类

这一版和现在的差别

  • 板上的就地输入框全摘了（BoardView.tsx:231-245 编辑态、:463-473 新卡草稿）——板只负责扫一眼和决定进哪张
  • ＋新卡不再往板上塞一张空卡：直接进详情，首次保存才写盘，中途返回无痕
  • 选中 = 外框亮起（--dsw-alias-brand-primary，浅 18.9:1 / 深 15.0:1）。原来那根浅蓝框在浅色主题只有 2.66:1
  • 分类不带颜色，靠图标 + 文字；蓝色全场只花在筛选 chip 和勾选框上
  • 分栏两栏等高封顶 + 按比例同步滚动（上面那两栏可以滚着看）

贴进来的东西怎么认

格式由内容嗅探，不让你选（card-format.ts:54-75 的规则：整份文档或以 markup 开头结尾且成对标签 ≥2 才算 HTML，否则一律 markdown）。三个「试贴」按钮走的就是这条判断。

  • md → 渲染态直接出标题 / 表格 / 引用
  • 网页 HTML → 渲染态换成沙箱 iframe（CanvasDetailView.tsx:72-88 已有）
  • 截图 → 卡里只多一行 ~200 字节的附件指针，像素进宿主附件库

后两条里，图片的写入与显示属阶段 ④，这里是示意形状，包内还没接。

分类随便改的边界

  • 改名、加、删都在这个画板内生效；五个现有分类是每个新画板的初始默认，不是不可动的内置常量
  • 删一个还有卡的分类 → 弹确认：那几张卡一起进归档，正文保留可恢复。不弹的话它们会在下次打开时凭空消失（types.ts:511 认不出的分类直接跳过整张卡）
  • 分类记录里没有颜色字段
  • 模型那侧写卡时用的候选名会跟着这个画板的目录走（tools.ts:64,156 的 enum 要改成动态）

整条属阶段 ⑤，这里是形状示意。

还没做的两件事

  • 自由绘画：详情页里画，笔画存成矢量 JSON 落进卡文本（就是普通文本卡，围栏 / 批注 / 归档全都现成）。要先给嗅探加 <svg 开头那条分支，否则画完显示的是源码
  • 让模型看见这张画：要先有"读板"工具，那是阶段 ③

透镜那一排按钮按你上轮的裁决原样留着，这次没动。

一句话：板只管挑卡，改和看都在详情；选中靠外框，分类靠文字；新卡不保存就不存在。
